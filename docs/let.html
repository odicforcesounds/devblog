Focados em problemas de Recuperação/Reparação

Muitas ferramentas usadas para recuperar sectores de arranque, para Windows ou Linux, e muitas outras com ferramentas de esteganografia para investigar discos e ficheiros. Como funciona como o velho HirensBoot, de que gosto, é provável que aprove a distro Linux Leng Engineer Toolkit para usar conforme for preciso.

Porque um sistema de recuperação ainda importa

Um disco de recuperação resolve um problema que o computador moderno esconde muito bem: quando a máquina não arranca, não se pode pedir ajuda ao sistema operativo que está dentro do disco. Precisas de outro sistema, a correr de outro sítio, com ferramentas suficientes para olhar para o disco como um objecto em vez de um lugar onde vivem os teus ficheiros.

É isso que é uma distribuição live. Não instala nada, não pede permissão, monta, inspecciona e reporta.

O que está dentro desta

Recuperação de sectores de arranque para Windows e Linux, que é a primeira coisa de que todos precisam e a última de que todos se lembram de preparar. Ferramentas para examinar um disco ao nível abaixo do sistema de ficheiros, onde uma partição apagada ainda é visível. E um conjunto de utilitários para dados escondidos, o tipo de trabalho que normalmente se chama forense quando é feito por um profissional e chama outra coisa quando é feito em casa.

A comparação com o HirensBoot é justa. Aquele disco antigo tinha a mesma filosofia: pôr todas as ferramentas de que um técnico precisa num só lugar, arrancar de um CD e deixar de te preocupares com o sistema que se recusou a arrancar.

A análise honesta

Aprovo-a porque faz um trabalho e fá-lo sem um instalador a pedir que crie uma conta. Uma caixa de ferramentas devia ser aborrecida: arrancar, listar, montar, copiar, verificar, sair. Se ainda por cima for bonita, isso é um bónus, não uma funcionalidade.

A única coisa que acrescentaria era uma página a dizer que ferramenta usar primeiro. Um disco cheio de utilitários é impressionante, mas às três da manhã o leitor precisa de um comando, não de um menu.

Focused on Rescue/Repair problems

Many tools used to recover boot sectors, for Windows or Linux and many other with steganos tools to investigate hard drivers and files. Since it works like the old HirensBoot, that I love it, I am likely to approve the Leng Engineer Toolkit Linux distro to use it as needed.

Why a rescue system still matters

A rescue disk solves a problem that the modern computer hides very well: when the machine does not boot, the operating system inside the disk cannot be asked for help. You need another system, running from somewhere else, with enough tools to look at the disk as an object instead of a place where your files live.

That is what a live distribution is. It does not install anything, it does not ask permission, it mounts, inspects and reports.

What is inside this one

Recovery of boot sectors for Windows and Linux, which is the first thing everyone needs and the last thing everyone remembers to prepare. Tools to examine a disk at the level below the file system, where a deleted partition is still visible. And a set of utilities for hidden data, the kind of work that is usually called forensics when it is done by a professional and called something else when it is done at home.

The comparison with HirensBoot is fair. That old disk had the same philosophy: put every tool a technician needs in one place, boot it from a CD, and stop worrying about the system that refused to start.

The honest review

I approve it because it does one job and does it without an installer asking me to create an account. A toolkit should be boring: boot, list, mount, copy, verify, leave. If it also looks nice, that is a bonus, not a feature.

The only thing I would add is a page that says which tool to use first. A disk full of utilities is impressive, but at three in the morning the reader needs one command, not a menu.
