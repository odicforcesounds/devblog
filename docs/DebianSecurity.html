    0. What Debian actually is (and why trust it)

    0.1 Free software as a security property

    Debian is not a company product. It is a volunteer association + social contract + constitution + DFSG (Debian Free Software Guidelines). Every package in main must satisfy DFSG: source available, modifiable, redistributable. Why paranoid people care: you can audit anything; no hidden telemetry blob is allowed in main. Non-free firmware lives separately in non-free-firmware — explicit, never silent.

    BranchUpdatesUse when
    Stable (bookworm)security + point releasesservers, heroes, exams
    Testing (trixie)rolling toward next stabledesktop, newer HW
    Unstable (sid)daily uploadsdevelopers only
    Experimentalno migrationnever on prod
    Enable only main + contrib + non-free-firmware (if needed) at install. Each extra repo is extra trust. Pin stable, never mix testing/unstable on a machine you care about unless you can pin + rollback.

    1. From ISO to encrypted disk

    1.1 Verify before you boot (most skipped, most critical)

    # on your CURRENT machine, before flashing USB:
sha256sum debian-12.7.0-amd64-netinst.iso
# compare to SHA256SUMS from debian.org, then verify signature:
gpg --verify SHA256SUMS.sign SHA256SUMS
Good signature from "Debian CD signing key"
    Flash with cp or Balena-independent dd status=progress bs=4M, then boot USB in UEFI mode (not Legacy/CSM) so you get GPT + ESP + Secure Boot path. Keep the signed checksums offline.

    1.3 Installer choices that matter

    • Partitioning: Guided → “Encrypted LVM” if unsure; Manual if you want ESP + /boot + LUKS as above.
    • Software selection: uncheck everything except SSH server + standard utilities for servers. Add desktop later via APT — smaller attack surface.
    • Root password vs sudo: set root password and create admin user → sudo path audited; empty root password locks root (Ubuntu-style).
    Debian Installer (d-i) + Calamares both produce reproducible, preseedable installs. Preseed file = infrastructure-as-code for bare metal.

    2.1 GRUB rescue is a hero skill

    grub> ls (hd0,gpt2)/boot   # find vmlinuz
grub> set root=(hd0,gpt2) | linux /vmlinuz root=/dev/mapper/vg-root | initrd /initrd.img | boot
    Enable Secure Boot (shim-signed + grub-efi-amd64-signed + kernel signed). Set UEFI admin password + disable USB boot in BIOS for kiosks/servers. GRUB password (grub-mkpasswd-pbkdf2) blocks single-user bypass via init=/bin/bash. Without it, “encrypted disk” still allows evil-maid on unencrypted /boot — mitigate with TPM2 + measured boot where possible.

    3.1 Kernel vs userspace

    Kernel = scheduler + memory + syscalls + drivers. Everything else (bash, apt, sshd) is userspace talking via syscalls (read, write, openat, execve, socket). Trace it: strace -e openat ls.

    3.3 Permissions lab — the famous rwx (interactive)

    LAB 3.3 — CHMOD SIMULATOR: toggle bits, see octal + ls -l

    owner group other
    octal: 644   ls -l: -rw-r--r--
    chown root:www-data file && chmod 640 file  # secret readable by group only
chmod +t /tmp  # sticky: only owner can delete own files (1xxx)
chmod u+s /usr/bin/sudo # setuid: run as owner (4xxx) — audit these!
find / -perm -4000 -type f 2>/dev/null  # list setuid — paranoid routine
    Default umask 027 (not 022) on multi-user machines so new files are not world-readable. Never chmod 777 — it is never the fix. Private keys 600, ~/.ssh 700, authorized_keys 600.

    LAB 5B — NFTABLES DEFAULT-DENY FIREWALL (toggle rules, test packets)

    Policy: deny all inbound except established + SSH (rate-limited) + HTTP/S. Try sending packets:

    ✔ allow ESTABLISHED ✔ allow SSH/22 (limit) ✔ allow 80/443 ✘ allow telnet/23 
    # real nftables equivalent (/etc/nftables.conf):
table inet filter {
  chain input { type filter hook input priority 0; policy drop;
    ct state established,related accept
    tcp dport 22 ct state new limit rate 5/minute accept
    tcp dport {80,443} accept; iif lo accept }
}
    Paranoid net: static IP via systemd-networkd on servers, NetworkManager only on laptops; DNS over TLS (systemd-resolved + Quad9); disable IPv6 only if you firewall it too (don’t ignore it); nftables default-drop inbound; no listening service you can’t name. Test from outside: nmap -sV yourhost.
