Diria que esta distro é bastante fixe, já que todos os LLM são Gratuitos e podemos acrescentar as chaves de API dos que não são.

Apresentam o «WebOS», que é uma abordagem interessante para um Desktop. O Mini Chess é Divertido.

Aplicação mesmo fixe, o Assistente de IA. Precisas de doar para ter acesso total a algumas funcionalidades, mas é suficientemente bom para um utilizador sem experiência.
