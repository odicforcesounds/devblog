Quando a fonte não faz referência a outras fontes

A documentação do OpenBSD não é má, mas podia ser melhor. De qualquer forma, o site do OpenBSD podia fazer referência a outros domínios com boa informação que podem ajudar os utilizadores do OpenBSD. Ler o manual é o que cada um pode fazer, mas a complexidade de preparar uma máquina com todos os detalhes necessários para configurar necessidades específicas nem sempre está descrita, o que nos leva a cometer mais erros.

Cometer erros é a forma como aprendemos, mas ter uma boa fonte de informação é melhor.
