    ⚖️ The One Rule to rule them all

    Least privilege → permission-free alternative → request in context → check before use → respect denial → re-check later.

    Every level teaches one piece of this loop.

    📜 Quick legend (real Android vocabulary)

    <uses-permission>Manifest declaration. Required, but never enough alone for dangerous perms.
    checkSelfPermission()Ask “do I have it right now?” before every protected action.
    RequestPermission launcherModern way to show system dialog & get result.
    shouldShowRequestPermissionRationale()Should I explain why before asking again?
    targetSdkVersionOpts you into newest permission behaviour. Play requires API 35+ (36 by Aug 2026).
