0 — Introduction: What Gentoo Is (And Is Not)

Welcome, new friend. If you know nothing about Gentoo, start here. Gentoo is a source-based Linux distribution. Most distributions give you prebuilt binaries. Gentoo gives you recipes called ebuilds and a package manager called Portage with its famous command emerge. You compile software for your machine with your flags. Result: total control, total learning, total responsibility.

This means install takes hours, sometimes days. Tip: this is normal. Gentoo is a teacher that charges tuition in compile time. You will choose init system (OpenRC default classic, or systemd), USE flags (global options like -gnome -kde pulseaudio), profile, kernel type, bootloader, filesystem. Nothing hidden.

Who should install Gentoo? Curious people who want to understand Linux from disk label to desktop pixel. Who should not? Anyone needing a 20-minute install before a meeting. Tip: keep a second computer or phone nearby for docs and coffee.

Official sources you will use constantly: Handbook:AMD64 overview, Full Installation guide, Gentoo Wiki, forums.gentoo.org, packages.gentoo.org, bugs.gentoo.org. Bookmark them now. Tip: never follow random blog commands blindly; always cross-check the Handbook version for your arch. Versions in this guide: arch amd64, UEFI + GPT assumed, OpenRC default with systemd notes.

What you need: 64-bit PC, 4 GB RAM minimum (8 GB+ happy), 40 GB disk minimum (100 GB+ for desktop + sources), wired net preferred, 8 GB USB stick, backup of all data. Tip: wired Ethernet saves hours of Wi-Fi firmware pain on first install. Time: 1 evening for base, 1-2 days for desktop + kernel + hardening.

Security mindset from zero: we will verify downloads, encrypt where sensible, harden kernel, use SELinux or AppArmor options, firewall with nftables, least privilege, updates. Tip: security is a process, not a package. Every step below has a security note.

1 — Boot Media, Networking, Disks

Step 1: get media from gentoo.org/downloads/amd64. Two flavors: Minimal Installation CD (small, text only) and LiveGUI (graphical). Tip: newbies take LiveGUI for comfort, Minimal for focus. Both boot same Handbook path. Verify checksum/signature per Handbook:AMD64/Installation/Media. Write with balenaEtcher, Rufus, Ventoy, or dd. Example: dd if=install-amd64-minimal.iso of=/dev/sdX bs=4M status=progress. Tip: triple-check /dev/sdX with lsblk or you wipe the wrong disk.

Boot in UEFI mode if target is UEFI. Connect net: NetworkManager on LiveGUI, or net-setup / ip + wpa_supplicant on Minimal. Test with ping 8.8.8.8 and ping gentoo.org. Tip: if Wi-Fi needs firmware, plug cable now; fight Wi-Fi after install. Set sshd password if you want remote help, and set clock with chrony / ntpd.

Step 2 — disks: see Handbook:AMD64/Installation/Disks. Use lsblk, fdisk -l, gdisk or parted. We assume UEFI + GPT. Layout: 1 GiB EFI System Partition FAT32, swap (match RAM if hibernate, else 4-8 GB), rest for root ext4 or btrfs or xfs + optional /home. Tip: separate /home saves future reinstall pain. LUKS-encrypt root/home now if laptop — see Security chapter.

Example with parted: mklabel gpt, mkpart ESP fat32 1MiB 1025MiB, set 1 esp on, mkpart swap 1025MiB 9GiB, mkpart root 9GiB 100%. Format: mkfs.fat -F32 /dev/nvme0n1p1, mkswap + swapon, mkfs.ext4 or mkfs.btrfs -L gentoo. Mount root at /mnt/gentoo, mkdir /mnt/gentoo/efi and mount ESP there (Handbook UEFI path) or /boot for BIOS layout. Tip: mount ESP at /efi for systemd-boot/dist-kernel style, at /boot/efi only if you know why.

Sources: Handbook Media, Handbook Disks, Arch Wiki EFI/GPT pages for background, Gentoo Wiki LUKS articles. Tip: photograph partition table with phone before formatting — future you says thanks.

2 — Stage3, Chroot, Portage Basics

Step 3 — stage: a stage 3 is your seed system, separate from ISO. Pick at gentoo.org/downloads/amd64 matching init: stage3-amd64-openrc or stage3-amd64-systemd, multilib default, desktop flavor if graphical (name contains desktop). See Handbook:AMD64/Installation/Stage. Tip: desktop stage saves hours of USE-flag wrestling for GNOME/KDE. Download + .DIGESTS + .asc, verify with sha512sum and gpg. Unpack with tar xpvf stage3-*.tar.xz --xattrs-include='*.*' --numeric-owner inside /mnt/gentoo. Tip: --numeric-owner and xattrs are not optional; skipping breaks permissions.

Step 4 — chroot: copy DNS: cp --dereference /etc/resolv.conf /mnt/gentoo/etc/. Mount proc sys dev run or use arch-chroot /mnt/gentoo helper. For UEFI mount ESP at /efi before chroot. See Handbook:AMD64/Installation/Base. Inside: emerge-webrsync to fetch Portage tree snapshot, then optional emerge --sync. Read news with eselect news read. Tip: always read news before first big emerge; it warns about profile/migration breakage.

Select profile: eselect profile list, eselect profile set N. Example desktop plasma or gnome, with systemd variant if needed. Check with eselect profile show. Configure make.conf: COMMON_FLAGS=-O2 -march=native -pipe, MAKEOPTS=-jN+1 where N=cores, USE flags, VIDEO_CARDS, INPUT_DEVICES, ACCEPT_LICENSE. Tip: -march=native is fast but binaries not portable; use generic x86-64 if you clone disks. Set eselect repository, mirrors with mirrorselect.

Configure system files: /etc/fstab (use UUIDs from blkid), hostname in /etc/conf.d/hostname (OpenRC) or /etc/hostname (systemd), timezone via eselect timezone / symlink /etc/localtime, locale in /etc/locale.gen + locale-gen + eselect locale, keymap, root password with passwd, networking (NetworkManager easiest for desktop, dhcpcd/netifrc for servers). Tip: UUID in fstab prevents boot fail after disk reorder.

Sources: Handbook Stage, Handbook Base, Wiki: Portage/Profiles, Wiki: MAKEOPTS, man make.conf, man emerge. Tip: keep a text log of every command; Gentoo forums love logs when helping.

3 — Kernel: Distribution vs Manual Compile

See Handbook:AMD64/Installation/Kernel. Three roads: sys-kernel/gentoo-kernel-bin (prebuilt, fastest, great for newbies), sys-kernel/gentoo-kernel (source-built distro kernel, auto updates, needs installkernel + initramfs), sys-kernel/gentoo-sources (fully manual, you configure/compile). Tip: start with -bin to get to desktop today, switch to manual later for learning.

Distro kernel path: emerge --ask sys-kernel/gentoo-kernel-bin sys-kernel/installkernel sys-kernel/dracut sys-firmware/linux-firmware sof-firmware sys-firmware/intel-microcode amd-ucode. Dracut builds initramfs for LUKS/LVM/btrfs. Check /efi or /boot for vmlinuz-6.x + initramfs. Tip: install linux-firmware + microcode before first boot or Wi-Fi/GPU may vanish. Enable installkernel USE for grub or systemd-boot layout.

Manual path: emerge --ask sys-kernel/gentoo-sources sys-apps/pciutils usbutils, cd /usr/src/linux, make menuconfig (needs ncurses). Essentials: 64-bit, EFI stub, NVMe, SATA AHCI, ext4/btrfs built-in not module if root, drm amdgpu/i915/nouveau, sound, USB, networking. Tip: run lspci -k and lsmod on LiveGUI, photo it, enable exactly that hardware first. Build: make -j$(nproc), make modules_install install. Takes 20 min to 2 hours by CPU. Keep .config backup in /root/kernel-config-YYYY-MM-DD.

Initramfs when needed (LUKS/LVM/btrfs/UEFI): dracut --hostonly --kver 6.x.y-gentoo or genkernel --install initramfs. Verify ls -lh /boot /efi. Tip: if root is LUKS, test cryptsetup open before reboot or you lock yourself out.

Sources: Handbook Kernel, Wiki: Kernel/Gentoo Kernel Upgrade Guide, Wiki: Dracut, Wiki: Genkernel, kernel.org docs. Tip: keep one known-good kernel + one new; never delete all old kernels.

4 — Bootloader, First Reboot, Post-Install Base

See Handbook:AMD64/Installation/Bootloader. Default sys-boot/grub handles BIOS+UEFI. UEFI alt sys-boot/systemd-boot (simple, fast). Install: emerge --ask sys-boot/grub efibootmgr os-prober (skip os-prober if single boot). grub-install --target=x86_64-efi --efi-directory=/efi --bootloader-id=Gentoo, then grub-mkconfig -o /boot/grub/grub.cfg. Tip: --efi-directory must match where you mounted ESP (/efi vs /boot); mismatch = unbootable.

For systemd-boot: bootctl install --esp-path=/efi, loader entries in /efi/loader/entries/gentoo.conf pointing to vmlinuz + initramfs + root UUID + rw. Tip: systemd-boot needs manual entry update per kernel unless installkernel hooks do it — check after each upgrade.

Exit chroot, unmount: exit, umount -l /mnt/gentoo/dev{/shm,/pts,}, umount -R /mnt/gentoo, reboot, remove USB. First boot: login root, check dmesg | grep -i -E 'error|firmware|fail', ip a, ping. Add user: useradd -m -G wheel,audio,video,usb,portage -s /bin/bash alice, passwd alice, install sudo + visudo (uncomment wheel). Tip: never daily-drive as root; sudo + wheel from day one.

Base update discipline: emerge --sync (or emaint sync -a), emerge --ask --verbose --update --deep --newuse @world, emerge --depclean, revdep-rebuild, eclean-dist --deep. Tip: update weekly, read elog with eselect news + elogv; small frequent merges beat yearly breakage.

Sources: Handbook Bootloader, Wiki: GRUB2, Wiki: Systemd-boot, man sudoers. Tip: snapshot btrfs subvolume or Clonezilla image right after first good boot.

5 — Kernel Hardening, MAC, Toolchain Security

Hardening is where Gentoo shines. Baseline: updated kernel (6.x stable, never ancient), least modules, Secure Boot with custom keys via sbctl or sbsigntools if threat model needs. Tip: enable Secure Boot only after normal boot works; debug one layer at a time.

Kernel self-protection (manual or via gentoo-kernel + sysctl): enable STACKPROTECTOR_STRONG, STRICT_KERNEL_RWX, STRICT_MODULE_RWX, SLAB_FREELIST_HARDENED, SHUFFLE_PAGE_ALLOCATOR, RANDOMIZE_BASE (KASLR), HARDENED_USERCOPY, SECURITY_LOCKDOWN_LSM, PAGE_TABLE_ISOLATION, RETPOLINE/IBRS mitigations, DEBUG_WX to find WX, disable /dev/mem /dev/kmem, LDISC_AUTOLOAD off, USER_NS_UNPRIVILEGED restrict if not needing containers. Tip: copy hardened .config fragment to /root and diff after each make olddefconfig. See Wiki: Hardened Gentoo, gentoo-hardened overlay, KSPP checklists.

Mandatory Access Control — pick one: SELinux (strongest, steepest; selinux-base-policy, relabel, setenforce 1) or AppArmor (easier, profiles via apparmor-utils, aa-enforce) . Tip: newbies start with AppArmor + firewall; graduate to SELinux on second install. Add hardened malloc via sys-libs/mimalloc-hw or hardened_malloc overlay for browsers, firejail or bubblewrap sandbox for Firefox.

Toolchain: gcc with -fstack-protector-strong -D_FORTIFY_SOURCE=2 -Wl,-z,RelRO,-z,Now -fPIE -pie via CFLAGS/LDFLAGS or hardened profile (eselect profile hardened). Enable PIE + RELRO + NOW + SSP, verify with hardening-check / checksec. Tip: hardened flags can break exotic packages; keep per-package exceptions in /etc/portage/env, not global weaken.

Boot/filesystem: LUKS2 (cryptsetup) with argon2id, detached header backup offline, fscrypt or eCryptfs only if needed, auditd rules for /etc/passwd /etc/shadow /boot, AIDE or samhain integrity DB on read-only USB. Tip: print LUKS recovery key on paper, store offsite; digital-only backup dies with disk.

Sources: Gentoo Hardened project, Wiki: SELinux, Wiki: AppArmor, KSPP (kernel self-protection), man cryptsetup. Tip: change one hardening knob per reboot so you know what broke boot.

6 — Desktop: Plasma / GNOME, Graphics, Sound

Pick profile first: eselect profile list | grep desktop, set default/linux/amd64/23.0/desktop/plasma or .../desktop/gnome (+ systemd variant if on systemd). Set VIDEO_CARDS=amdgpu radeon intel nvidia as needed, INPUT_DEVICES=libinput synaptics. Tip: wrong VIDEO_CARDS = black screen; lspci | grep -i vga first.

X or Wayland: xorg-server + xinit for classic, or Wayland via plasma-meta / gnome sessions. Install: emerge --ask kde-plasma/plasma-meta kde-apps/kdecore-meta sddm for KDE Plasma, or emerge --ask gnome-base/gnome gdm for GNOME. Lighter: i3, sway, Xfce via xfce4-meta. Enable DM: rc-update add sddm default (OpenRC) or systemctl enable sddm (systemd). Tip: test with startx as user before enabling DM; DM hides errors.

Firmware + microcode + graphics: linux-firmware amdgpu-ucode intel-microcode amd-ucode mesa vulkan-loader libva-vdpau-driver, kernel DRM built-in. Sound: pipewire wireplumber pipewire-pulse alsa-utils pavucontrol. Tip: PipeWire + WirePlumber is modern default; enable pipewire service per user. Fonts: noto, corefonts, fontconfig. Printing: cups. Bluetooth: bluez.

Apps baseline: firefox (set USE=hardened pie), thunderbird, libreoffice, vlc, gimp, keepassxc, flatpak optional for closed apps. Tip: Flatpak for Spotify/Discord/Steam keeps base clean; native emerge for everything else.

Sources: Wiki: KDE, Wiki: GNOME, Wiki: Xorg, Wiki: PipeWire, eselect profile docs. Tip: emerge -pv before big desktop merge to see USE changes; veto surprises early.

7 — Network, Firewall, SSH, Updates, Backups

Firewall default-deny with nftables (modern) or iptables legacy. Install nftables, enable, rules: allow lo, established, 22 only from LAN if needed, 80/443 out, drop rest, rate-limit SSH 3/min. Or use ufw / firewalld wrapper. Tip: test firewall over console first; lockout over SSH with no IPMI is a long walk. Add fail2ban for SSH, usbguard for BadUSB.

SSH: openssh, PermitRootLogin no, PasswordAuthentication no (keys in ~/.ssh/authorized_keys 600), Port 2222 optional, AllowUsers alice. Tip: ssh-copy-id then disable passwords; one key leak beats thousand brute forces. VPN: wireguard-tools for road warriors. DNS: systemd-resolved or dnscrypt-proxy + DNSSEC.

Updates + integrity: weekly emaint sync -a; emerge -uDN @world; emerge --depclean; revdep-rebuild; eclean-dist -d; updatedb; aide --check. Enable elogv / eselect news. Backups: borgbackup or restic to external LUKS disk + offsite, test restore quarterly. Tip: untested backup is rumor. Restore one file now to prove it works.

Browser + user hardening: Firefox with uBlock Origin, NoScript or uMatrix, KeepassXC, separate profiles, bubblewrap / flatpak sandbox. Tip: Wayland + PipeWire + Flatpak Firefox is safest easy desktop sandbox.

Sources: Wiki: Nftables, Wiki: OpenSSH, Wiki: WireGuard, Gentoo Security Handbook. Tip: run lynis audit or tiger check quarterly; fix reds first.

8 — Extra Security, Tips, Troubleshooting, Next Steps

Extra: securelevel via sysctl kernel.kexec_load_disabled=1 kernel.dmesg_restrict=1 kernel.kptr_restrict=2 kernel.perf_event_paranoid=2 kernel.unprivileged_bpf_disabled=2 net.core.bpf_jit_harden=2 vm.mmap_rnd_bits=32 in /etc/sysctl.d/99-hardening.conf. sys-kernel/linux-firmware minimal (strip unused). Disable Bluetooth/Thunderbolt in BIOS if unused. Tip: sysctl + reboot + sysctl -a | grep setting to confirm; typos silently fail.

Physical: BIOS password, boot order lock, LUKS + TPM2 + PIN via clevis optional, screen lock 5 min, usbguard block new devices when locked. Tip: encrypt swap or disable hibernate; cleartext swap leaks keys. Supply chain: verify ISOs, use gpg, app-portage/gemato, avoid random overlays; add eselect repository overlays sparingly.

Troubleshooting: no boot? Check ESP mount, grub.cfg UUIDs, dracut --regenerate-all. Black screen? VIDEO_CARDS + firmware + eselect opengl. No net? dhcpcd vs NetworkManager conflict — pick one. Merge fail? Read build.log, emerge --info, search bugs.gentoo.org + forums with exact error. Tip: pastebin emerge --info + build log when asking help; helpers ignore vague 'it broke'.

Next: join forums, IRC #gentoo, Reddit r/Gentoo, read GWN weekly news. Try distcc/ccache for speed, binpkg host for laptops. Tip: ccache size 10-20 GB cuts recompiles massively on desktop.

Tip: keep this HTML offline on USB; best rescue disk is docs you own.
