Data Ingestion & Tokenization

Before raw data can enter an artificial intelligence pipeline, unstructured input (text, images, audio) undergoes rigorous parsing. For Large Language Models (LLMs), text strings are split into discrete sub-word tokens using algorithms like Byte-Pair Encoding (BPE) or WordPiece.

Each token is mapped to an immutable integer index within a pre-defined vocabulary matrix $V$, typically containing between 32,000 to over 250,000 distinct tokens.

  • Raw String: "Cyberpunk AI Core"
  • Token Sequence: `["Cyber", "punk", " AI", " Core"]`
  • Vocabulary IDs: `[14280, 18439, 9374, 5821]`
# Python implementation of basic BPE Tokenization Simulation import re class SimpleTokenizer: def __init__(self, vocab): self.vocab = vocab self.inv_vocab = {v: k for k, v in vocab.items()} def encode(self, text: str) -> list: # Regex tokenizer partition tokens = re.findall(r'\w+|[^\w\s]', text) return [self.vocab.get(t, 0) for t in tokens] # Execution Core vocab_map = {"Cyber": 101, "punk": 102, "AI": 103} tokenizer = SimpleTokenizer(vocab_map) token_ids = tokenizer.encode("Cyber punk AI") print(token_ids) # Output: [101, 102, 103]

Vectorization & Embeddings

Integer IDs lack semantic meaning (e.g., token 500 isn't "greater" than token 100). The embedding layer transforms discrete token indices into continuous, high-dimensional dense vectors $\mathbb{x} \in \mathbb{R}^d$ (where dimension $d$ ranges from 768 to 12,800+).

Furthermore, because transformers process inputs in parallel rather than sequentially, Positional Encodings or Rotary Embeddings (RoPE) are added directly to token vectors to encode word order and relative distance.

$\mathbf{H}_0 = \text{Embedding}(X) + \text{PositionalEncoding}$
import torch import torch.nn as nn class EmbeddingPipeline(nn.Module): def __init__(self, vocab_size, d_model): super().__init__() self.token_embed = nn.Embedding(vocab_size, d_model) self.pos_embed = nn.Embedding(512, d_model) def forward(self, input_ids): seq_len = input_ids.size(1) positions = torch.arange(0, seq_len, device=input_ids.device) # Combine semantic and positional vectors out = self.token_embed(input_ids) + self.pos_embed(positions) return out

Neural Network Forward Pass & Matrix Operations

The core computational engine of modern deep learning relies on massive matrix multiplications (GEMM). At each linear layer, incoming activation tensors $\mathbf{X}$ are multiplied by weight matrices $\mathbf{W}$ and added to bias vectors $\mathbf{b}$.

In attention mechanisms (Transformers), this expands into Query ($\mathbf{Q}$), Key ($\mathbf{K}$), and Value ($\mathbf{V}$) projections:

$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}}\right)\mathbf{V}$

Hardware accelerators (GPUs/TPUs) parallelize these dot-product operations across thousands of streaming multiprocessors simultaneously.

import math import torch import torch.nn.functional as F def scaled_dot_product_attention(Q, K, V): d_k = Q.size(-1) # Matrix multiplication of Query and Transposed Key scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k) # Normalization via Softmax weights = F.softmax(scores, dim=-1) # Final dot product with Value matrix return torch.matmul(weights, V), weights

Activation Functions (ReLU / GELU)

Linear transformations alone stack into a single linear operation. Activation functions introduce non-linearity, enabling artificial neural networks to approximate complex, non-linear functions (Universal Approximation Theorem).

  • ReLU (Rectified Linear Unit): $\text{ReLU}(x) = \max(0, x)$. Computationally fast, prevents vanishing gradients for positive inputs.
  • GELU (Gaussian Error Linear Unit): Weights inputs by their relative magnitude, widely used in modern transformer architectures like GPT and BERT.
import torch import torch.nn as nn class CustomActivations: @staticmethod def relu(x): return torch.clamp(x, min=0.0) @staticmethod def gelu(x): # Gaussian Error Linear Unit approximation return 0.5 * x * (1.0 + torch.tanh( math.sqrt(2.0 / math.pi) * (x + 0.044715 * torch.pow(x, 3)) ))

Backpropagation & Gradient Descent

During training, the model evaluates its prediction error against ground truth targets using a Loss Function (e.g., Cross-Entropy Loss).

Backpropagation applies the chain rule of calculus in reverse order, calculating the partial derivative of the loss with respect to every weight parameter in the network ($\frac{\partial L}{\partial W}$).

$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$

Optimizers like AdamW use adaptive learning rates and momentum vectors to update weights efficiently across high-dimensional loss landscapes.

import torch import torch.optim as optim # Dummy model and optimizer setup model = torch.nn.Linear(10, 2) optimizer = optim.AdamW(model.parameters(), lr=1e-3) criterion = torch.nn.CrossEntropyLoss() # Training Step Iteration optimizer.zero_grad() # Clear stale gradients outputs = model(torch.randn(4, 10)) loss = criterion(outputs, torch.tensor([1, 0, 1, 0])) loss.backward() # Compute gradients via backprop optimizer.step() # Update weights via gradient descent
