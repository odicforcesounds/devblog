Memory management is Awesome but Everything else is Hell

An old Gentoo post at this blog, describe how bad their Handbook is, since the Team didn't create a dedicated manual for OpenRC with all necessary instructions to complete the installation by the default configurations, mixing everything with SystemD and many other articles that could be in a separated page like many other articles are, but for SystemD, "Heil SystemD" is what Gentoo would say.

So, I try to install Gentoo using OpenRC and naturally using the packages gentoo-sources. I found that you need to install dracut to generate the initramfs file, but extra steps are needed, while their Stupid Handbook don't describe them and therefor after few hours later, I quit.

The Sakaki user was more sensible to this aspect and create a separated version for OpenRC and other to SystemD. I really think that some members from Forum and IRC are like "gods", but their documentation is like a Chicken. So, I spend some hours to try. I was just giving them a try, but yeah, they give up to make things organized.

Another "Joke" is that the official mirrors don't have a no-multilib-hardener image or stage3 available, while using eselect profile list that profile is there. So, they assume that, if you wish to setup a no-multilib-hardener system, you need to compile everything. Damn... I suggest Gentoo to stick with ./configure and make, without using scripts like Portage. After all, Gentoo Freedom is a Lie. Users don't have any Freedom, but Hell.

Is like trying to install MongoDB. If you include USE="mongosh", you will have a cycle problem with Go that ask the same version as a dependency. What? Yeah. Non-Sense. The same version that you need to install, is blocking that same version to install. O_o Is this that you call Freedom Gentoo? To solve the "Freedom Problem" you need to install the Binary package. LoL ( how freedom is for Gentoo ) ... Binary Packages... for that I use Debian!

Using Debian, I have total freedom to install what ever I wish, to create what ever partitions I wish and much much more, wasting less than 1 hour to install and configure everything. That is what Freedom is about! Is a system that give me the Opportunity to Enjoy Time (doing whatever I like to do with my Own Time) ... That is Freedom!
