Gerir um servidor será uma experiência fantástica para mim, já que presto sempre atenção à Segurança, e como não tenho intenções de usar a maioria das ferramentas Ofensivas, adoro mesmo usar as Ferramentas Defensivas. Por isso, é bom bloquear, não todos, mas alguns, e o Fail2Ban pode ajudar. A Internet é fantástica, e encontramos sempre alguém com o mesmo problema ou com alguma solução. Um serviço de Geolocalização nos nossos servidores é uma boa abordagem para entender os atacantes, mas não desejo entendê-los e, portanto, um Banimento permanente é a melhor escolha.
