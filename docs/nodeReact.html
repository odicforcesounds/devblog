NodeJS & ReactJS

Em Referência a Mergulhar no Mundo do JavaScript

Depois de ler quase 100.000 livros (artigos) sobre ReactJS e NodeJS, finalmente descobri que preciso de usar os dois.

O NodeJS é feito para comunicações de Backend, como ficheiros ou bases de dados.

O ReactJS é feito para melhorar o Frontend, como a UI e o Comportamento da Página.

Enquanto desenvolvo o STK (Social Tool Kit) do site principal do domínio odicforcesounds.com com ReactNative, descobri que não preciso de aprender mais do que estas duas «Frameworks».

Quer dizer, o NodeJS não é uma Framework, mas JavaScript para Máquinas (fora do Navegador), enquanto o ReactJS é uma Framework baseada em JavaScript.

Gosto mesmo do estilo de estrutura de dados do MongoDB, também conhecido como NoSQL. Parece super simples, comparado com MySQL ou PostgreeSQL, embora usar serviços externos como Firebase ou Supabase seja uma escolha opcional.

Sim, acho que vou usar a minha máquina antiga (portátil) para guardar os dados das duas aplicações. A aplicação STK e a Livraria que preciso de construir para começar a vender alguns livros. [Em referência ao último post]

Nalgumas perspectivas odeio o ReactJS, já que ADORO sites estáticos com HTML e CSS estáticos, como todos os meus sites são.

Mas preciso de me forçar a melhorar as minhas competências e abraçar o Futuro.

Então acho que vou começar a escrever um pouco mais no meu Blog de Desenvolvimento para me guiar a entender os pequenos / grandes detalhes dos dois.

Não é uma afirmação contraditória. Pequenos detalhes podem resultar em Grandes resultados. É como fazer uma Viagem Espacial à Lua. Se um pequeno detalhe falha, pode resultar numa Grande falha, como uma grande grande Explosão.

E o Grande é também o resultado de várias peças que são pequenas, que juntas fazem uma única peça que é Grande.

É como eu e tu. O teu corpo é o Grande resultado de muitas peças pequenas que juntas fazem o todo daquilo que está em ti.

Se um pequeno fragmento de ti falhar, todas as outras peças de ti falharão também.

Como gosto de dizer: «Sou apenas um Macaco e todos os Macacos fazem barulho, ao avisar do perigo, sendo animais pacíficos».

Não tentes magoar-me. Os Grandes estão a vigiar para evitar esse acontecimento. E se acontecer, os Grandes ficarão tão Loucos que vais desejar pará-los, mas a única condição para os parar está em mim.

Por isso, deixa-me fazer o que preciso e desfruta da tua vida como deves.

Continua a Rockar e Desfruta do Espectáculo!

NodeJS & ReactJS

In Reference of Dive into the World of JavaScript

After reading almost 100.000 books ( articles ) about ReactJS and NodeJS, I finally found that I need to use both.

NodeJS is made to Backend communications, like files or databases.

ReactJS is made to improve the Frontend, like the UI and Page-Behavior.

While I am developing the STK ( Social Tool Kit ) from the main website of odicforcesounds.com domain with ReactNative, I found that I don’t need to learn more than this two “Frameworks”.

I mean, NodeJS is not a Framework, but JavaScript for Machines ( outside the Browser ), while ReactJS is a Framework based on JavaScript.

I really like the MongoDB aka NoSQL data structure style. It looks super simple, compared to MySQL or PostgreeSQL, while using external services like Firebase or Supabase is an optional choice.

Yes, I think I will use my old-machine (laptop) to store the data of both applications. The STK application and the Bookstore that I need to build to start selling some books. [In reference of the last post]

Is some perspectives I hate ReactJS, since I LOVE static websites with static HTML and CSS, like all my sites are.

But I need to force me to improve my skills and embrace the Future.

So, I think I will start to write a bit more in my Developing Blog to guide me to understand small / big details of both.

Is not a contradictory afirmation. Small details can result in Big results. Is like making a SpaceTrip to the Moon. If a Small details fails, can result in a Big failure, like a big big Explosion.

While the Big is as well, the result of several pieces that are small, while together make one single piece that is Big.

Is like me and you. Your body is the Big result of many small pieces that together make the whole of what is on you.

If a small fragment of you fail, all other pieces from you will fail too.

As I like to say: “I am just a Monkey and all Monkeys are noisy, as they warn about the danger, while being peaceful animals”.

Don’t try to hurt me. The Bigs are watching to prevent that event. And if it happen, the Big will become so Crazhy that you will wish to stop them, but the only condition to stop them is on me.
