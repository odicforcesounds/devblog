How Hacking Happens — And How To Stop It

Blue team to understand attack paths. Red team to break them. Lab only. No real targets without written permission. Ever.

Ethics first — read or close this file: Only hack systems you own or are explicitly authorized to test (your lab, CTF, bug-bounty scope). Unauthorized access, credential cracking against real accounts, malware, ransomware, doxxing = crimes. This manual teaches concepts + defense + lab practice, not how to break into real systems. If in doubt, defend.

0 — Map: Hats, Teams, Bounties

White hat: authorized defender/researcher. Black hat: criminal. Gray hat: unauthorized but claims good intent — still illegal, don't. Red team: authorized adversary emulation. Blue team: detect/respond/harden. Purple: both collaborate. Bug bounty: legal hacking inside a scope + rules (see HackerOne, Bugcrowd, GitHub Security Lab). Start with OWASP Top 10 + OWASP Testing Guide.

Papers to read (defensive lens): NIST SP 800 series (800-53, 800-115 testing), MITRE ATT&CK (adversary tactics map), Cyber Kill Chain (Lockheed), NIST Incident Handling 800-61.

1 — Lab, Not Real Life: Isolate Your Experiments

Build a lab you can break without breaking law or others:

Host: Debian/Ubuntu, updated, firewall on
Hypervisor: VirtualBox (https://www.virtualbox.org/) or KVM/QEMU + virt-manager
Net: Host-only / NAT, NO bridge to home LAN for vulnerable VMs
Targets (vulnerable-by-design, local only):
  - Metasploitable 2/3 (https://github.com/rapid7/metasploitable3)
  - OWASP Juice Shop (https://github.com/juice-shop/juice-shop)
  - DVWA (https://github.com/digininja/DVWA)
  - WebGoat (https://github.com/WebGoat/WebGoat)
Attacker: Kali Linux (https://www.kali.org/) as a toolbox, snapshots before/after
Capture: Wireshark (https://www.wireshark.org/) on host-only only
Snapshot everything. Lab firewall: vulnerable VMs must never reach internet. No real credentials, no real data, no scanning outside 192.168.56.0/24 lab range.

Secure your lab: separate user, encrypted disk (LUKS docs), ufw deny incoming on host, VPN kill-switch if you must fetch tools, GPG-verify ISOs.

2 — How Attacks Are Structured (Kill Chain → ATT&CK, Defensive View)

Recon → weaponize → deliver → exploit → install → command → act. Map each to ATT&CK tactics. Blue counters: harden, detect, segment, log, respond. Example: phishing (Initial Access) fails if MFA + user training + mail filtering win. Study NIST CSF: Govern/Identify/Protect/Detect/Respond/Recover.

3 — Recon & Scanning: What Attackers See, How Defenders Shrink It

Concept: DNS, subdomains, ports, services, versions leak attack surface. Tools defenders use to audit own scope: Nmap (nmap.org, github/nmap), Amass (owasp-amass), theHarvester (theHarvester), Shodan (shodan.io — defender search for own exposure).

# LAB ONLY against your own VMs, e.g. 192.168.56.101:
nmap -sV -O 192.168.56.101   # versions, OS guess — then YOU patch/hide them
# Blue: close ports, least service, banner minimization, WAF/CDN in front
Blue lesson: every open port/version you see, attacker sees. Inventory with Nmap, then firewall, update, segment. Log scans with Suricata/Snort.

4 — Web: The #1 Real-World Path (Understand → Fix)

Learn OWASP Top 10: injection, broken access control, XSS, SSRF, misconfig. Practice defensively on Juice Shop/DVWA locally; intercept with Burp Suite Community (portswigger) or OWASP ZAP (zaproxy, github).

Defense pattern (the point): parameterize queries, ORM, allow-list validation (Zod), output-encode, CSP + HttpOnly/SameSite cookies via Helmet (helmetjs), strict access checks server-side, SSRF allow-lists + no cloud metadata access. Scan own code with Semgrep, deps with Grype.

5 — C Fundamentals: Stack, Memory, Why Safe Code Matters

You don't need to exploit to defend — but you must grasp why memory bugs are critical. Theory only, lab only:

// stack frame (simplified x86-64): high -> low
// [args][ret addr][saved rbp][locals: char buf[64]]
// Unsafe copy can overflow locals -> crash/hijack in theory.
// Defense: -fstack-protector-strong -D_FORTIFY_SOURCE=2 -Wl,-z,RelRO,-z,Now -fPIE -pie
// + ASLR, NX, canaries, fuzzing, modern langs (Rust/Go) for new code.

Learn safely: RPISEC MBE (course), pwn.college (ASU, lab + defense), awesome-pwn (curated learning), papers: Smashing the Stack (Phrack 49, historic) — read as history + why mitigations exist. Practice defense: compile with protections, run ASan/UBSan, fuzz with AFL++ on your own code, verify with checksec/hardening-check.

6 — Passwords/Cracking: Why We Harden Auth (No Real Cracking)

Concept: weak/reused passwords + no MFA = breach. Attackers use leaked lists + guessing in theory; your job is to make it fail: long unique passwords in KeePassXC (keepassxc.org), MFA everywhere (TOTP/WebAuthn), bcrypt/argon2 server-side, rate-limit + lockout, breach monitoring (HIBP). Audit own hashes in lab only with John (openwall) / Hashcat (hashcat) docs to prove policy works — never against others.

7 — Blue Team: Detect, Log, Respond

Tools: Wireshark (wireshark) for packets, Suricata/Snort IDS, Wazuh (wazuh, github) SIEM, TheHive+Cortex (TheHive) case mgmt, Velociraptor (velociraptor) DFIR, Ghidra (ghidra, NSA github) for malware analysis in isolated VM. Playbooks: NIST 800-61, SANS whitepapers.

Log centrally, time-sync (NTP), alert on ATT&CK techniques you actually see in lab, rehearse restore from offline backups. Blue wins by preparation, not heroics.

8 — Bug Bounty Path (Legal Hacking Career)

1) Learn web + networking basics. 2) Lab: Juice Shop → PortSwigger Academy (portswigger academy). 3) Read scopes twice, respect out-of-scope, rate limits, disclosure rules. 4) Report: repro, impact, fix. Repos: OWASP WSTG checklist, HackTricks (defensive reference — use on own scope only), PayloadsAllTheThings (test payloads for own lab/scope). Never extort, never pivot beyond scope, never access real user data.

9 — Study Plan (6 Weeks, Lab + Defense)

W1 Linux+networking + lab build. W2 OWASP Top 10 on Juice Shop + fix code. W3 Nmap/ZAP on own VMs + harden. W4 C/memory theory + compiler mitigations + fuzz own toy program. W5 Blue: Suricata+Wazuh alerts + IR drill. W6 Bounty-style report on lab target with fix PR. Throughout: ATT&CK mapping, write-ups, clean snapshots.

Hack to protect. Learn stacks to build safer stacks. The best hacker on your network is the defender you trained.
