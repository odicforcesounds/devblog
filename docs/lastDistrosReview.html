Apenas outro Irmão/Irmã do Kali Linux

Depois de prestar um pouco mais de atenção, percebo que esta distro usa IA no nome. Não tenho a certeza, mas parece. Enfim, esta distro é baseada no Kali Linux e quer oferecer algo novo, embora na minha experiência não tenha oferecido nada de todo, já que o browser OSINT dedicado se mata sozinho ao tentar arrancar, mas a framework OSINT offline funciona bem e o manual online também funciona bem, onde podemos ler um pouco mais sobre cada ferramenta.

De facto, uma das ferramentas da lista são ferramentas de IA, mas não as testei. Só nessa experiência de correr os programas predefinidos sem explorar todas as ferramentas, as aplicações predefinidas funcionam bem e a web não nota a minha máquina a usar algum sistema suspeito, como o Kali Linux faz. Com esta Distro Linux de Investigação, posso visitar o Google e o Google não me vai pedir para verificar se sou ou não um Bot. Parece que o Google já Marcou o Kali Linux como mau, o que significa que os utilizadores de Kali Linux não são muito Éticos. É apenas outro problema muito comum ao lançar ferramentas que podem «magoar» os outros, de graça.

Nesta experiência rápida, vou aprovar esta Distro específica, mesmo que devessem corrigir esse bug no browser OSINT deles. Vou guardá-la, já que nos permite correr o sistema sem instalar num disco.

Just another Brother/Sister of Kali Linux

After paying a bit more attention, I figure out that this distro name use AI in their Distro name. I am not sure, but it looks like that. Anyway, this distro is based on Kali Linux and wish to offer something new, while in my experience didn't offer anything at all, since their dedicated OSINT browser does a auto-killed after trying to start, but the offline OSINT framework works fine and their online manual is working fine too, where we can read a bit more about each tool.

In fact one of the list tools is AI tools, but I didn't test them. Only in that experience of running the default programs without exploring all the tools, the default applicatons work fine and the web don't notice my machine as using some suspecious system, like Kali Linux does. With this Research Linux Distro, I can visit Google and Google will not ask me to verify if I am or not a Bot. It looks like Google already Flag Kali Linux to be bad, which means that Users using Kali Linux are not very Ethical. That is just another problem that is very common when releasing tools that can "hurt" others, freely.

In this fast experience, I will approve this specific Distro, even if they should fix that bug on their OSINT browser. I will save it, since it allow us to run it without installing on a hard drive.
