Lets imagine that we use Debian or Ubuntu-Server for your machine. Is not a Docker, but a dedicated server to host your website at home. Since you are using cloudflare to proxy your domain into your host machines, you know that you only need to setup a server with a HTTP server with SSL, that cloudflare already offer. This machine it is on your local host network. Maybe you have physical access to it and therefor, you don't need to setup SSH. For each tunnel from cloudflare you need a dedicated machine for that, but we want to enable other protocol, while cloudflare does not support other protocols. We are glad that what cloudflare support can be done within other machines on our network to serve other services. We may wish to have a database, but we only give network access to our local machines, hidding the better we know, all kind of sensitive information. This can be your web application, that needs to be secure. Naturally you may wish to hide HTTP Server Version to hardener your attackers life, since anyone can search the web for exploits against your HTTP server version and own your server without knowing "how to read". I always like to change the default port for SSH server to ensure that only those who did a port scan against your machine, can see what port is. You prevent all king of automatic attacks from bots or real persons. If you follow all recommendations to secure your servers, without being paranoid, you don't need to worry about attacks, because you hide all protocols and info that is sensitive. Sladly you need to run databases as a root user or by the sudo command, but if your database server is not exposed, no one can access it.

So we can think about the default configurations that most everyone in the world have. Assuming that, you have a Internet service and your ISP ask you money to use their own router that is controlled by them, in part. Anyway, from the modem-router you have at least 4 Ethernet ports and you can buy a simple switch to connect many other pcs. Normally your intranet IP is 192.168.1.2 and you want to add 3 more or even more. If you don't use their wifi, just turn it off. You know that the one that is exposed, is secured by cloudflare free tunnel services and everything else is controlled by you inside your own network that is not exposed. You can use one single machine to hosts many different sites using docker but right now, I see docker as a complex tecnology. I prefer Qemu, that give me a better nothing of what configurations I am using for that Virtual host and I can use a dedicated shell to interact with. But if you understand how Docker works, you can run many different applications, isolated from all others (in theory), while you can go deeper and use FreeBSD and setup Jails or by using OpenBSD and setup VMMs.
