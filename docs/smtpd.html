Mail: How SMTP/POP/IMAP Work + OpenSMTPD Setup

Mail = send (SMTP) + store + retrieve (IMAP/POP). Specs: RFC 5321 SMTP, RFC 1939 POP3, RFC 9051 IMAP4rev2. OpenSMTPD: opensmtpd.org, smtpd.conf man.

0 — Roles In One Picture

MUA (Thunderbird/mutt) --[SMTP :587 submit]--> MSA/MTA (OpenSMTPD/Postfix)
  --[SMTP :25 relay + MX lookup]--> recipient MTA → Maildir/Mailbox
MUA <--[IMAP :993 (sync) | POP3 :995 (download-delete)]-- mailbox (Dovecot)
# ports: 25 server→server, 587 submission (STARTTLS+auth), 465 SMTPS legacy, 993/995 TLS retrieve

1 — SMTP: Push Mail (Talk Like A Server)

# try safely against YOUR server:
openssl s_client -connect mail.example.com:587 -starttls smtp
EHLO client.example.com
AUTH LOGIN  (base64 user/pass — or PLAIN/OAUTH2)
MAIL FROM:<you@example.com>
RCPT TO:<friend@example.org>
DATA
Subject: hi
Hello. .
QUIT
# server checks: reverse DNS, SPF (TXT), DKIM sign, DMARC policy, greylist/spam (rspamd)
MSA (587) requires auth+TLS; MTA-to-MTA (25) uses MX + opportunistic TLS. Open relay (anyone→anywhere, no auth) = instant blacklist. Never enable.

2 — IMAP vs POP (Pull Mail)

IMAP :993 (modern default)POP3 :995 (simple/legacy)
ModelSync: mail stays server-side, folders/flags/SEARCH server-side. All devices mirror.Download: fetch then usually delete. One device owns mail.
Tryopenssl s_client -connect mail.example.com:993 → a LOGIN user pass → a LIST "" "*" → a SELECT INBOXopenssl s_client -connect mail.example.com:995 → USER u → PASS p → LIST/RETR 1/QUIT
Use whenMulti-device, server sieve/filter, shared folders.Single offline box, tiny server, backup-and-purge.

Retrieval server: Dovecot (dovecot.org). Spam/filter: rspamd (rspamd.com). OpenSMTPD sends; Dovecot serves IMAP.

3 — DNS Mail Must-Haves (Before You Configure)

example.com.      300 IN MX 10 mail.example.com.
mail.example.com. 300 IN A 203.0.113.10
_hr._tcp... no — SPF: example.com. 300 IN TXT "v=spf1 mx -all"
DKIM: selector._domainkey 300 IN TXT "v=DKIM1; k=rsa; p=MIIB..."
DMARC: _dmarc 300 IN TXT "v=DMARC1; p=quarantine; rua=mailto:dmarc@example.com"
PTR: 10.113.0.203.in-addr.arpa. IN PTR mail.example.com.

4 — OpenSMTPD On Debian (Send Path)

sudo apt install -y opensmtpd opensmtpd-filter-rspamd
# /etc/smtpd.conf — minimal relay with auth + TLS, local delivery to Dovecot/LMTP or Maildir
pki mail.example.com cert "/etc/ssl/mail.example.com.fullchain.pem"
pki mail.example.com key "/etc/ssl/private/mail.example.com.key"
table aliases file:/etc/aliases
table users passwd:/etc/smtpd/passwd   # smtpctl encrypt for passwords
listen on eth0 tls pki mail.example.com
listen on lo0
action "local" maildir "/var/mail/%{user.username}" 
action "relay" relay
match from any for domain example.com action "local"
match from auth for any action "relay"
# check + reload:
smtpd -n; systemctl restart opensmtpd; smtpctl show stats; tail -f /var/log/maillog
# cert: certbot certonly --standalone -d mail.example.com (https://certbot.eff.org/)
Debian's opensmtpd package + smtpd.conf syntax (OpenBSD-portable). Keep lingo: pki/listen/action/match. Test with swaks (swaks): swaks --to you@example.com --from you@example.com -tls -au user.

5 — Pair With Dovecot IMAP (Receive Path)

sudo apt install -y dovecot-imapd
# /etc/dovecot/conf.d/10-mail.conf: mail_location = maildir:/var/mail/%u
# /etc/dovecot/conf.d/10-ssl.conf: ssl_cert/<key paths same as above; disable plaintext: disable_plaintext_auth=yes
systemctl restart dovecot
# Thunderbird (https://www.thunderbird.net/) → IMAP mail.example.com:993 SSL, SMTP mail.example.com:587 STARTTLS+auth
Anti-abuse before first mail: SPF+DKIM+DMARC valid, rDNS matches HELO, no open relay (nmap -p 25 --script smtp-open-relay YOU in lab), rate-limit auth + fail2ban, backups of /var/mail + /etc/smtpd.conf + keys encrypted.

Refs: OpenSMTPD, smtpd man, Dovecot docs, rspamd docs, mxtoolbox.com (MX/SPF/DKIM check).

SMTP pushes, IMAP syncs, POP takes. OpenSMTPD routes with two verbs: listen + match.
