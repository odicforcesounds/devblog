curl — Complete Manual

Transfer URLs, test APIs, debug TLS. Docs: curl.se, manpage, Everything curl (free book).

0 — First Five Commands

curl https://example.com                 # GET, print body
curl -I https://example.com              # HEAD: headers only (-I)
curl -v https://example.com              # verbose: DNS+TLS+req/resp (king of debug)
curl -L https://example.com              # follow redirects (-L)
curl -o out.html https://example.com     # save to file (-o); -O uses remote name
Trio for life: -v see truth, -L follow, -sS silent but show errors. Add -w for timing (below).

1 — Options Explained (The Ones That Matter)

OptionPlain meaning + when
-X GET/POST/PUT/DELETEForce method. GET default; POST with -d. Use --request long form in scripts.
-H 'K: V'Add header. -H 'Authorization: Bearer X' -H 'Content-Type: application/json'. Repeatable.
-d 'a=1&b=2' / --json '{"a":1}'Body. -d = form + POST; --json sets JSON type + POST. --data-binary @file exact bytes.
-F file=@a.png / -F 'x=1'Multipart upload (forms/files). @ reads file. For pure binary PUT: -T file.
-u user:pass / --netrcBasic auth. Prefer header/token; .netrc 600 beats shell history. Never -u with secrets inline on shared box.
-b/-c cookies.txtSend (-b) / save (-c) cookies. -b '' enables engine without file.
-e ref / -A agentReferer + User-Agent spoof for testing variants.
-k / --cacert CA.pem-k skips verify (lab only!); --cacert trusts private CA properly.
--cert/--key/--tlsv1.3mTLS + version pin. Debug ciphers: --ciphers.
-x proxy / --noproxyProxy + bypass list. Env https_proxy also read.
--resolve h:443:IP / --connect-toOverride DNS/SNI for staging tests without /etc/hosts.
-m 10 / --connect-timeout 5 --retry 3Timeouts + retries. Always set -m in scripts or hangs forever.
-sS -o /dev/null -w '%{http_code} %{time_total}\n'Health-check pattern: silent, code + seconds. Full vars below.
-D headers.txt / -iDump headers to file (-D) or prefix body (-i = include).

2 — Normal Usage (Daily Bread)

# JSON API GET with token:
curl -sS -H "Authorization: Bearer $TOKEN" https://api.example.com/notes | jq .
# POST JSON:
curl -sS -X POST -H 'Content-Type: application/json' -d '{"title":"hi"}' https://api.example.com/notes
# form login + cookies:
curl -sS -c jar.txt -d 'user=a&pass=b' https://example.com/login
curl -sS -b jar.txt https://example.com/me
# upload:
curl -F 'file=@report.pdf' -F 'note=final' https://example.com/upload
# download resume:
curl -L -C - -O https://example.com/big.iso
# headers/status only:
curl -sSI https://example.com | head -20

3 — Testing APIs Like A Pro

# pretty + fail on HTTP error:
curl -sSf http://127.0.0.1:3000/api/health
# timing breakdown:
curl -o /dev/null -sS -w 'code:%{http_code} dns:%{time_namelookup} tls:%{time_appconnect} ttfb:%{time_starttransfer} total:%{time_total}\n' https://api.example.com/
# all methods smoke test:
for m in GET POST PUT DELETE; do echo -n "$m: "; curl -s -o /dev/null -w '%{http_code}\n' -X $m http://127.0.0.1:3000/api/notes; done
# load-ish (10 parallel):
seq 1 10 | xargs -P10 -I{} curl -s -o /dev/null -w '{}
%{http_code}\n' http://127.0.0.1:3000/api/health
# Contract: diff live vs golden JSON (keys sorted):
curl -s http://127.0.0.1:3000/api/notes | jq -S . > live.json; diff golden.json live.json
In CI assert http_code==200 + JSON schema (jq -e), not just "didn't crash". Save -D headers on failure.

4 — TLS / Auth / Proxy Debugging

curl -v https://expired.badssl.com/              # see verify fail (https://badssl.com/)
curl -k https://self-signed.local/               # LAB ONLY bypass
curl --cacert ./myCA.pem https://internal.local/ # right way: trust CA
curl --resolve api.example.com:443:10.0.0.5 https://api.example.com/  # staging IP
curl -x http://127.0.0.1:8080 -k https://api.example.com/  # via Burp/ZAP (lab)
curl --cert client.pem --key client.key https://mtls.local/
curl -v --tlsv1.3 https://api.example.com/ 2>&1 | grep -i -E 'cipher|TLS|cert'
Secrets hygiene: prefer env vars + ~/.netrc (600), never paste tokens in tickets. history -c after manual token test.

5 — Scripts That Don't Hang At 3am

#!/bin/bash
set -euo pipefail
code=$(curl -sS -m 10 -o /tmp/body -w '%{http_code}' https://api.example.com/health)
[[ "$code" == "200" ]] || { echo "bad $code"; cat /tmp/body; exit 1; }
# config file for repeats: ~/.curlrc or -K file
# -K deploy.conf:
#   silent=true
#   show-error=true
#   max-time=10

6 — Cheat Pairs (curl ↔ what it means)

curl -I=headers? -v=why fail? -L=redirect loop? --resolve=DNS lie? -k=cert or bypass? -w time_*=slow DNS/TLS/TTFB? Pair with dig, openssl s_client -connect h:443 -servername h, tcpdump port 443.

Refs: Everything curl, man, github/curl, badssl.com (test beds).

Verbose first, assume nothing, time everything. curl never lies — servers do.
