1 — Types You'll Use Daily

// narrow > any. Unknown in, validated out:
function parseNote(u: unknown): { title: string } {
  if (typeof u !== 'object' || u === null || !('title' in u)) throw new Error('bad');
  const { title } = u as { title: unknown };
  if (typeof title !== 'string' || !title.trim()) throw new Error('bad title');
  return { title: title.trim() };
}
type Result<T> = { ok: true; data: T } | { ok: false; error: string };

2 — Builtins: Where They Live

Language: lib.*.d.ts on github/microsoft/TypeScript/src/lib (DOM, ES2022...). Node: nodejs.org/api + @types/node (fs/promises, path, crypto, http). Browse in editor: F12 on any global → jumps to .d.ts. That's the source of truth.

4 — Web-App Best Practices (Frontend + API)

Shared contract: packages/contracts/note.ts with Zod schemas imported by client + server — one truth, no drift. Never any across boundary; parse with schema.parse(). Errors as values: Result<T>, never throw raw DB errors to client. Auth: HttpOnly Secure SameSite cookies, short JWT, refresh rotate. Render: React/Next.js or Vite — type props, no implicit any, useState<Note[]>.

// api/src/routes/notes.ts
import { z } from 'zod';
const Note = z.object({ title: z.string().trim().min(1).max(200) });
app.post('/api/notes', async (req, res) => {
  const body = Note.parse(req.body); // 400 via error middleware on throw
  res.status(201).json({ ok: true, data: body });
});
Lint+format in CI: typescript-eslint + Prettier + tsc --noEmit. Green pipeline or no merge.
