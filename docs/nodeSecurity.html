Node.js Paranoid Security on Debian: Own The Server, Expose Nothing

Mindset: you own the server, so you distrust everything else — code, packages, users, bots, even yourself at 2am. Application below: a tiny secure notes API (Node.js + Express) behind Nginx on Debian 12. Every tip is obsessive on purpose. If it feels excessive, good — attackers are excessive.

0 — The App We Harden (So Tips Have Teeth)

Stack: Node.js 20 LTS (nodejs.org), Express 4 (expressjs.com), PostgreSQL 15 (postgresql.org) or SQLite for tiny, Nginx (nginx.org) reverse proxy, PM2 or systemd (pm2), Debian 12 Bookworm (debian.org), UFW/nftables (Debian nftables), Fail2ban (fail2ban.org), Certbot (certbot.eff.org).

PARANOID RULE #1: never commit .env. Ever. .env in git = public secret. Add to .gitignore day zero, rotate any key that touched git history with Gitleaks.
node --version # v20.x
project/
  server.js  routes/  middleware/
  .env  (600, root:www-data? NO — app user only)
  .gitignore -> .env, node_modules, *.log, *.pem

1 — Debian Base: Minimal, Updated, Boring (Boring = Safe)

Install minimal Debian, no desktop. Create deploy user, kill root SSH. Tip in spirit: if you don't need it, uninstall it.

apt update && apt full-upgrade -y
apt install -y unattended-upgrades apt-listchanges sudo ufw fail2ban unattended-upgrades
useradd -m -s /bin/bash deploy
usermod -aG sudo deploy
# /etc/ssh/sshd_config: PermitRootLogin no, PasswordAuthentication no, AllowUsers deploy
systemctl restart ssh
ufw default deny incoming; ufw default allow outgoing
ufw allow 22/tcp; ufw allow 80/tcp; ufw allow 443/tcp; ufw enable
# auto security updates:
dpkg-reconfigure -plow unattended-upgrades
✔ Enable unattended-upgrades for security only. Full auto-upgrade can break Node; security-only + weekly manual apt full-upgrade in maintenance window.

Links: Debian UnattendedUpgrades, Debian SSH, Debian Security.

2 — .env & Secrets: The Crown Jewels (Treat Like Nuclear Codes)

PARANOID RULE #2: .env lives once, on server, chmod 600, owned by app user. No backups to Dropbox. No Slack pastes. No console.log(process.env).
# /opt/notesapp/.env — chmod 600, chown notesapp:notesapp
PORT=127.0.0.1:3000
DATABASE_URL=postgres://notesapp:'S0mething-Long-32chars'@127.0.0.1:5432/notes
SESSION_SECRET=$(openssl rand -hex 32)
# load with dotenv ONLY in dev; in prod use systemd EnvironmentFile
npm i dotenv # https://www.npmjs.com/package/dotenv

Better than .env on your own server: systemd EnvironmentFile=/etc/notesapp/env (600 root, read at start, never in repo), or HashiCorp Vault (vaultproject.io) / SOPS (mozilla/sops) for rotation. Validate at boot with dotenv-safe or Zod — crash if SESSION_SECRET < 32 chars.

✔ Scan repo pre-commit with Gitleaks + git-secrets. Add .env.example with fake values only.

3 — Node App Hardening: Headers, Limits, Injection-Proof

npm i express helmet cors express-rate-limit express-mongo-sanitize xss-clean hpp cookie-parser csurf jsonwebtoken bcrypt pg zod
# https://www.npmjs.com/package/helmet — sets 11+ secure headers
// server.js — paranoid skeleton
const helmet = require('helmet');
app.disable('x-powered-by');
app.use(helmet({ contentSecurityPolicy: { directives: { defaultSrc: ["'self'"] } }, hsts: { maxAge: 31536000, includeSubDomains: true, preload: true } }));
app.use(express.json({ limit: '10kb' })); // no 10MB JSON bombs
const limiter = require('express-rate-limit')({ windowMs: 15*60*1000, max: 100, standardHeaders: true });
app.use('/api/', limiter);
// auth: bcrypt cost 12, jwt 15min + refresh rotate, httpOnly SameSite=Strict Secure cookies
// validate every input with zod; parameterize SQL (pg $1); no string concat
PARANOID RULE #3: trust no input — not body, query, header, file, webhook. OWASP NodeJS Cheat Sheet is bedtime reading.

Deps: npm audit; npm audit fix, automate with Grype / Snyk / Dependabot. Pin with package-lock.json, npm ci --omit=dev in prod. Never npm install as root.

4 — Run As Nobody: systemd, Non-Root, Read-Only Where Possible

# /etc/systemd/system/notesapp.service
[Service]
User=notesapp
Group=notesapp
WorkingDirectory=/opt/notesapp
EnvironmentFile=/etc/notesapp/env
ExecStart=/usr/bin/node /opt/notesapp/server.js
Restart=always
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/notesapp/logs
AmbientCapabilities=
# UMask=0077 so logs 600
✔ App binds 127.0.0.1:3000 only. World talks to Nginx, never Node directly. ss -tlnp must show Node on localhost.

5 — Nginx Shield: TLS, No Leaks, No .env Ever Served

Nginx docs, Mozilla SSL config.

server {
  listen 443 ssl http2; server_name api.example.com;
  ssl_certificate /etc/letsencrypt/live/api.example.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/api.example.com/privkey.pem;
  add_header X-Content-Type-Options nosniff always;
  add_header X-Frame-Options DENY always;
  add_header Referrer-Policy no-referrer always;
  client_max_body_size 1m;
  location / { proxy_pass http://127.0.0.1:3000; proxy_set_header X-Forwarded-For $remote_addr; }
  location ~ /\. { deny all; }  # block .env, .git
  location ~* \.(env|pem|key|sql|bak)$ { deny all; }
}
# certbot --nginx -d api.example.com  (https://certbot.eff.org/)
# test: curl -I https://api.example.com/.env must be 403/404, never 200
PARANOID RULE #4: static root never contains code. root /var/www/public holds only built assets. .git never deployed — deploy tarball via rsync --exclude='.git --exclude=.env'.

6 — Data: Postgres Locked Down, Backups Encrypted

# Postgres listens localhost only, scram-sha-256, least privilege:
# /etc/postgresql/15/main/postgresql.conf: listen_addresses='127.0.0.1'
# pg_hba.conf: host notes notesapp 127.0.0.1/32 scram-sha-256
CREATE USER notesapp WITH PASSWORD 'long-random';
CREATE DATABASE notes OWNER notesapp; REVOKE ALL ON DATABASE notes FROM PUBLIC;
# backups: pg_dump | gpg --encrypt | restic to offsite (https://restic.net/)

Encrypt backups with GnuPG, store keys offline. Test restore quarterly. Log with pgaudit for sensitive tables.

7 — Perimeter: Fail2ban, Monitoring, No Phone-Home

[nginx-limit-req] enabled=true
[sshd] maxretry=3 bantime=1h

# monitor: Uptime Kuma (https://github.com/louislam/uptime-kuma) self-hosted, AIDE (https://aide.github.io/) integrity
✔ Run Lynis audit monthly. Redact secrets from logs: logLevel warn, never log tokens, mask with pino-noir (pino-noir).
