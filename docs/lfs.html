LFS — Linux From Scratch: From Zero to a Booted OS

You start with a running Linux host and an empty partition. You end with your own compiled Linux system that boots without the host. No installer, no package manager — every binary built by you, in order. Based on LFS 13.1-systemd (2026, kernel 7.1.8, GCC 16.2, glibc 2.44, Binutils 2.47). Older stable: 12.4. News: lfs/news. Overview: how LFS builds.

Rules: follow ONE book version exactly — never mix versions. Backup the host. Disk names below (/dev/sda) are examples — use lsblk for yours. Full build takes 4–12h depending on CPU. 4 cores + 8GB RAM recommended.

1. What LFS Is (and Is Not)

LFS is a recipe book, not a distro. It teaches: cross-toolchain → temp tools → chroot → final system → kernel → bootloader. You learn what a distro hides: how glibc talks to the kernel, why build order matters, what /tools isolation is for.

LFS gives youLFS does NOT give you
Minimal bootable systemd Linux, sources + patchesPackage manager, desktop, wifi wizard
Deep understanding of toolchainSecurity updates automatically (you rebuild)
Base for BLFS (desktop, server on top)Shortcuts — every package compiled in order

After LFS comes BLFS (Beyond LFS) for X, desktop, network services.

2. Host Preparation

Ref: host requirements. Host kernel ≥ 5.10, bash, gcc, binutils, bison, coreutils, make, perl, python3, etc.

# Run the book's version-check script (download from book ch.2), then:
bash version-check.sh
# Must all pass. On Debian/Ubuntu, roughly:
sudo apt install build-essential bison gawk m4 texinfo python3 libncurses-dev
uname -r   # >= 5.10 ?
ls -l /bin/sh   # must point to bash, NOT dash: sudo dpkg-reconfigure dash
Host GCC newer than the book's (16.2) or binutils newer than 2.47 = untested. Prefer a host close to the book. First-timers: do NOT add custom CFLAGS — chapter 8 warns optimizations break builds.

3. Partition, Filesystem, Mount

Ref: partitioning, filesystems. Need ≥10GB, 30GB comfortable, ~20GB sweet spot. ext4 default. UEFI needs ESP 128–256MB; BIOS+GPT needs BIOS Boot partition; optional 200MB /boot.

lsblk                 # IDENTIFY your empty disk/partition first!
sudo cfdisk /dev/sdb  # example: sdb1 512M EFI (if UEFI), sdb2 30G Linux, sdb3 swap
sudo mkfs.ext4 /dev/sdb2
sudo mkfs.vfat -F32 /dev/sdb1   # only if UEFI ESP
sudo mkswap /dev/sdb3; sudo swapon /dev/sdb3
export LFS=/mnt/lfs   # book convention — keep in every shell!
sudo mkdir -pv $LFS; sudo mount -v -t ext4 /dev/sdb2 $LFS
# Save it: echo "export LFS=/mnt/lfs" >> ~/.bashrc

4. Sources, Layout, lfs User

sudo mkdir -v $LFS/sources; sudo chmod -v a+wt $LFS/sources
# Download all tarballs + patches listed in book ch.3-4 (wget-list in book)
sudo mkdir -pv $LFS/{etc,var,tools} $LFS/usr/{bin,lib,sbin}
sudo groupadd lfs; sudo useradd -s /bin/bash -g lfs -m -k /dev/null lfs
sudo chown -v lfs $LFS/{usr/*,lib,var,etc,bin,sbin,tools,sources}
su - lfs
cat > ~/.bash_profile <<'EOF'
exec env -i HOME=$HOME TERM=$TERM PS1='\u:\w\$ ' /bin/bash
EOF
cat > ~/.bashrc <<'EOF'
set +h; umask 022; LFS=/mnt/lfs
LC_ALL=POSIX; LFS_TGT=$(uname -m)-lfs-linux-gnu; PATH=/usr/bin
[ ! -L /bin ] || PATH=/bin:$PATH
PATH=$LFS/tools/bin:$PATH; CONFIG_SITE=$LFS/usr/share/config.site
export LFS LC_ALL LFS_TGT PATH CONFIG_SITE MAKEFLAGS=-j$(nproc)
EOF
source ~/.bash_profile; echo $LFS_TGT   # e.g. x86_64-lfs-linux-gnu

Ref: lfs user. Building as lfs protects the host; root only where the book says.

5. Cross-Toolchain (Chapter 5) — Isolation From Host

Goal: compiler that outputs for $LFS without linking host libs. Order matters: Binutils pass 1 → GCC pass 1 (limited, no full libc yet) → Linux headers → glibc → libstdc++.

# Pattern for EVERY package (exact flags in book — copy them, don't improvise):
tar xf binutils-2.47.tar.xz; cd binutils-2.47
mkdir -v build; cd build
../configure --prefix=$LFS/tools --with-sysroot=$LFS \
  --target=$LFS_TGT --disable-nls --disable-werror
make; make install; cd ../..; rm -rf binutils-2.47 build
# Then GCC pass 1 (needs mpfr/gmp/mpc unpacked INSIDE gcc dir per book),
# then: linux-7.1.8 headers 'make headers', then glibc 2.44, then libstdc++.
# Sanity check after toolchain:
echo 'int main(){}' | $LFS_TGT-gcc -xc - -v -o /tmp/a.out 2>&1 | grep -i sysroot
Why two passes? Pass 1 builds with host help. Later (ch.6) Binutils/GCC pass 2 rebuild using the new libc inside $LFS — cutting the cord to the host.

6. Temporary Tools (Chapter 6) + Enter Chroot (Chapter 7)

Ref: ch.6 intro. Cross-compile m4, ncurses, bash, coreutils, diffutils, file, findutils, gawk, grep, gzip, make, patch, sed, tar, xz, binutils pass 2, gcc pass 2 — installed under $LFS/tools and $LFS/usr.

# As root (exit lfs user), mount virtual filesystems:
sudo mount -v --bind /dev $LFS/dev
sudo mount -vt devpts devpts $LFS/dev/pts -o gid=5,mode=0620
sudo mount -vt proc proc $LFS/proc
sudo mount -vt sysfs sysfs $LFS/sys
sudo mount -vt tmpfs shm $LFS/dev/shm
# Then chroot — /tools/bin GONE from PATH now, target tools used:
sudo chroot "$LFS" /usr/bin/env -i HOME=/root TERM="$TERM" \
  PS1='(lfs chroot) \u:\w\$ ' PATH=/usr/bin:/usr/sbin /bin/bash --login
# Ref: https://www.linuxfromscratch.org/lfs/view/13.1-systemd/chapter07/chroot.html
# Inside: ch.7 temp tools + cleanup /tools.

7. Final System (Chapter 8) — The Real Build

Ref: ch.8 intro, contents. ~70 packages in strict order: glibc (final) → binutils → gcc → … → systemd → grub. Each follows configure/make/test/install; run tests where book says (GCC/glibc tests take long but catch breakage).

# Inside chroot, example rhythm (READ book flags per package!):
tar xf glibc-2.44.tar.xz; cd glibc-2.44
mkdir -v build; cd build
../configure --prefix=/usr --disable-werror --enable-kernel=5.10 \
  --enable-stack-protector=strong --disable-nscd libc_cv_slibdir=/usr/lib
make; make check   # expect some failures — book lists which are OK
make install; cd ../..; rm -rf glibc-2.44 build
# Continue per book: zlib, bzip2, xz, zstd, file, readline, m4, bc, flex,
# binutils, gmp/mpfr/mpc, attr/acl, shadow, gcc (final), ncurses, sed,
# psmisc, gettext, bison, grep, bash, libtool, gdbm, gperf, expat, inetutils,
# less, perl, XML::Parser, intel-ucode?, libffi, openssl, python3, ninja,
# meson, kmod, libelf, libffi, e2fsprogs, coreutils, ..., systemd, ..., grub.
Common failures: skipped make check confusion (compare with book's expected fails), wrong timezone of errors from custom CFLAGS, running out of disk (need ~10GB free during gcc), /dev not mounted before udev/systemd steps.

8. System Configuration (Chapter 9)

# fstab — ADAPT UUIDs (blkid):
cat > /etc/fstab <<'EOF'
# file-sys  mount  type  opts          dump fsck
/dev/sdb2   /      ext4  defaults      1    1
/dev/sdb1   /boot/efi vfat defaults   0    2
/dev/sdb3   swap   swap  pri=1         0    0
proc        /proc  proc  nosuid,noexec,nodev 0 0
sysfs       /sys   sysfs nosuid,noexec,nodev 0 0
devpts      /dev/pts devpts gid=5,mode=620 0 0
tmpfs       /run   tmpfs defaults      0    0
devtmpfs    /dev   devtmpfs mode=0755,nosuid 0 0
EOF

echo "lfsbox" > /etc/hostname
passwd root
ln -sfv /usr/share/zoneinfo/Europe/Lisbon /etc/localtime
# systemd-networkd .network file per book; systemctl enable systemd-networkd systemd-resolved

9. Kernel + Bootloader (Chapter 10) → First Boot (Ch.11)

Ref: kernel, grub. Disable Secure Boot (book procedure doesn't support it).

# In chroot, /sources:
tar xf linux-7.1.8.tar.xz; cd linux-7.1.8
make mrproper
make defconfig; make menuconfig
# MUST enable: your disk (AHCI/NVMe!), ext4, EFI stub if UEFI, SMP.
make -j$(nproc); make modules_install
cp -v arch/x86/boot/bzImage /boot/vmlinuz-7.1.8-lfs
cp -v System.map /boot/System.map-7.1.8; cp -v .config /boot/config-7.1.8
# GRUB BIOS: grub-install /dev/sdb --target=i386-pc   (whole disk, CAREFUL)
# GRUB UEFI: mount ESP at /boot/efi, then:
grub-install --target=x86_64-efi --removable
cat > /boot/grub/grub.cfg <<'EOF'
set default=0; set timeout=5
menuentry "LFS 13.1" {
  linux /vmlinuz-7.1.8-lfs root=/dev/sdb2 ro
}
EOF
exit   # leave chroot
sudo umount -Rv $LFS/dev/shm $LFS/dev/pts $LFS/{sys,proc,run,dev} $LFS 2>/dev/null
sudo reboot  # select LFS disk in BIOS/UEFI
Booted? Login as root → uname -a; systemctl status. You now run a self-built OS. Next: BLFS for networking extras, firmware, editor, SSH, desktop.
