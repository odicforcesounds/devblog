All Bots are welcome

As you may see, this is a open source project and you can clone it and open a pull request.

Sadly for your bots, I use Cloudflare, which is something that depend on them, not on me. ;)

A bot is only a program with a schedule

There is nothing evil in a bot. A crawler that reads this page to build an index, an archiver that keeps a copy for the future, a script that checks whether the site is still alive at three in the morning: all of those are polite, useful and welcome. They arrive once, they read, they leave, and they come back when it makes sense.

The unfriendly part is never the automation, it is the control. When a thousand machines repeat the same request in the same second and none of them was invited, the site is not being read, it is being tested for weakness. The difference between a reader and an attack is not the tool, it is the intention behind the schedule.

So nothing here is a secret

The source of this blog is public. You can clone it, read it, fork it and open a pull request. If you find a spelling mistake, a broken link or a paragraph that makes no sense, tell me and I will be grateful. That is the whole point of working in the open: the correction is free and it arrives from someone who was paying attention.

What is not public is the right to hammer the server. That decision is not mine anyway. Cloudflare decides which request is a browser and which request is a machine in a hurry, and I only see the result in the statistics. If your bot is challenged, it is not because I dislike bots, it is because the line between a crawler and a flood is thinner than it looks from the outside.

What a bot can still do here

Read the text. Follow the links. Take the RSS feed if you want the articles in your terminal. Keep a copy for an archive. Every one of those things is a compliment to a writer, and every one of those things costs almost nothing to serve.

Just do not try to see how many requests per second the server can take. The answer is in the configuration, and the configuration is already boring. ;)
