Anyway, If you use a Web application project with .env file, you may wish to not use that node library. Instead, save your variables on your the $SHELL.

Edit your ~/.bashrc file and add something similar
export mongoDB="mongo://192.213.123.13" # some comments
export mongoPass="Som3Str4n6E-Pa$$"
Then update your variables by commiting the next command in the $SHELL
source ~/.bashrc

Then, on your nodejs application, you access the variables by using the process.env.

const mdb = process.env.mongoDB;
const pdb = process.env.mongoPass;
console.log(mdb, pdb);
