TCP Packets In Detail

TCP = reliable ordered byte stream over IP. Docs: RFC 793, RFC 9293 (obsoletes 793), Wireshark TCP wiki.

2 — Handshake / Data / Close (Annotated)

# tcpdump -i lo -nn 'port 3000'
1. C→S [S]      seq 1000                       # "can we talk? ISN=1000"
2. S→C [S.]     seq 5000, ack 1001             # "yes. ISN=5000, got yours"
3. C→S [.]      ack 5001                       # "got yours. open."
4. C→S [P.]     seq 1001:1101, ack 5001, len 100  # 100B request
5. S→C [P.]     seq 5001:5201, ack 1101, len 200  # 200B reply
6. C→S [F.]     seq 1101, ack 5201             # "done sending"
7. S→C [F.]     seq 5201, ack 1102             # "done too"
8. C→S [.]      ack 5202                       # closed. (RST aborts instantly.)
Wireshark filters: tcp.flags.syn==1 && tcp.flags.ack==0 (opens), tcp.analysis.retransmission, tcp.window_size==0 (stalled receiver).

3 — Live Examples (Your Lab)

# 1. Watch handshake to local app:
sudo tcpdump -i lo -nn 'port 3000'
# (other shell) curl http://127.0.0.1:3000/api/health
# expect S → S. → ACK → P./ACK → F./F.

# 2. Full options decode:
sudo tcpdump -i any -nn -vv -s0 'host 192.168.56.101 and port 80' -c 3
# look: mss 1460, wscale 7, sackOK, TS val, nop padding

# 3. Retransmit hunt:
sudo tcpdump -i eth0 -nn 'host DB and port 5432' | grep -i -E 'retrans|dup'
# many = MTU/firewall/NIC. Probe: ping -M do -s 1472 DB

# 4. RST vs FIN close:
curl http://127.0.0.1:3000/ & sleep 0.2; ss -tnp | grep 3000
# FIN = polite; RST = killed (timeout, crash, firewall reject)

4 — Numbers That Bite (MSS/MTU/Window)

Ethernet 1500 − IP 20 − TCP 20 = MSS 1460. Below: 1460 in SYN. Above 1500 (tunnels/VPN) fragments or drops — fix MTU/MSS-clamp. Window × WSCALE = true buffer (e.g. 64240×256 ≈ 16MB). Small/zero window + big app queue = slow receiver, not slow net. SACK lets re-send only holes; without it, go-back-N wastes.

5 — Cheat: tcpdump ↔ Wireshark ↔ Cause

[S] no reply = filtered/port closed. [R] after SYN = refused. Dup ACK storm = loss. Zero window = app stuck. RST mid-stream = timeout/crash/policy. Pair with ss -tin (retrans/rtt/cwnd), ip -s link (errors/drops).

Refs: RFC 9293, TCP wiki, tcpdump man.

Seq counts bytes, Ack wants next, Flags tell story, Window tells capacity. Read four, know the connection.
