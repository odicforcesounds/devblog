Noções básicas de FreeBSD: pkg

Pacotes binários é o que o pkg sabe instalar.

Corre o pkg no terminal e instala ou atualiza o pacote pkg.

pkg help install
pkg update -f
pkg upgrade
pkg search string
pkg install string
pkg info
pkg audit -F
pkg delete string
pkg autoremove
pkg prime-list
pkg prime-origins
pkg clean
pkg lock string
pkg unlock string

Notas gerais

Num artigo antigo falo de uma experiência antiga com /usr/ports, que me pediu para instalar o servidor X quando tentava instalar editors/vim. Com o gestor de pacotes pkg, podes escolher a melhor opção para ti. O string é vim.
