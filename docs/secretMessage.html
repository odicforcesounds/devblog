It is not a secret, it is a shift

A secret needs a key, and a key needs to be shared with someone you trust. What is written above needs nothing: every letter was moved a few places along the alphabet, the same amount for all of them. You can undo it with a pencil, a piece of paper and the patience of a child, which is exactly why it is not a secret.

Julius Caesar used this idea because it was fast, not because it was safe. His enemies could not read the message on the road, and that was enough for a message that only had to survive one afternoon. Today the same text would be opened by any student in a first lesson about cryptography.

The lesson is in the difference

People often confuse encoding with encryption. Encoding changes the shape of a message so a machine can carry it. Encryption changes it so nobody can read it without the key. The first one is a container, the second one is a lock. When a company hides a password with an encoding, it is not protecting the password, it is decorating it.

So this page is a joke with a purpose. If you can read it, the method failed as a secret and succeeded as a lesson. If you cannot read it yet, the title is already telling you what to use.

Try it before you search for it

Write the alphabet on a line, write it again underneath, and move the second line three letters to the left. Now read the message by looking for each letter below instead of above. It takes about five minutes the first time, and after that you will see why a real cipher needs to be much more than a shift.
