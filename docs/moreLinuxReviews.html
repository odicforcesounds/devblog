O lado mau de algumas Distros Nixovena

Enquanto o Zen Clora Linux funciona como esperado, o Overkill Linux apresenta problemas a ligar à internet em Modo Live, enquanto o HardenWing não liga à internet ao tentar instalar. Sem modo live nesta última distro, o que significa que as distros Harden que testei até agora apresentam problemas que muitas outras não têm.

O Zenclora Linux usa transparência em todos os menus e só ocupa 700MB de RAM para o usar. Consumo bastante normal se o comparar com uma instalação Debian normal com Desktop MATE. Por isso, o ZenClora Linux está aprovado, enquanto o Overkill e o HardenWing Linux não estão.

The bad side of some Nixovena Distros

While Zen Clora Linux works as expected, the Overkill Linux present problems connecting into the internet using in Live Mode, while the HardenWing does not connect into the internet when trying to install. No live mode on this last distro, which means that the Harden distros that I test so far, present some problems that many others don't.

Zenclora Linux use transparency in all menus and only takes 700MB of RAM to use it. Pretty normal consume if I compare it to a normal Debian installation with MATE Desktop. Therefor, the ZenClora Linux is approved, while Overkill and HardenWing Linux are not.
