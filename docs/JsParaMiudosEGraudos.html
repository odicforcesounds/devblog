Módulo 0: A Origem de um Superpoder

Antes de escrevermos código, precisamos entender o nosso universo. O JavaScript (JS) nasceu em 1995, criado por Brendan Eich na empresa Netscape. Surpreendentemente, ele foi criado em apenas 10 dias!

Se a Web fosse uma pessoa:

  • HTML é o esqueleto (a estrutura, ossos).
  • CSS é a roupa e a maquilhagem (o visual, estilo).
  • JavaScript é o cérebro, os músculos e o sistema nervoso (a inteligência, reações e dinamismo).
O JavaScript corre diretamente no teu navegador (browser) sem precisar de instalar programas complexos. É a linguagem que faz os jogos web, botões interativos e animações funcionarem.

Módulo 1: As Caixas Mágicas (Variáveis e Tipos de Dados)

Para programar, precisamos de guardar informação na memória do computador. Fazemos isso usando variáveis. Pensa nelas como caixas onde colamos uma etiqueta com um nome.

// Criamos uma caixa chamada 'nomeHeroi' e guardamos um texto (String)
let nomeHeroi = "Alex";

// Criamos uma caixa constante (que não muda) chamada 'idade' com um número
const idade = 12;

// Uma variável lógica (Boolean) que diz se ele está ativo
let estaAtivo = true;

Tipos de Dados Fundamentais:

  • String: Sequência de caracteres (texto), sempre entre aspas ("Olá").
  • Number: Números inteiros ou decimais (12, 3.14).
  • Boolean: Verdadeiro (true) ou Falso (false).

Módulo 2: O Grimório Secreto (A Documentação Oficial)

Nenhum herói memoriza todos os feitiços do mundo. Os programadores usam a documentação oficial, sendo a mais famosa a MDN Web Docs (Mozilla Developer Network).

Quando lês a documentação, encontras a sintaxe (como escrever) e os parâmetros (o que a função precisa para funcionar). Por exemplo, a documentação explica que a função console.log() serve para imprimir mensagens na consola do navegador para testes.

Módulo 3: Tomando Decisões (Lógica e Condicionais)

Um programa inteligente precisa de tomar decisões, tal como tu quando decides se levas guarda-chuva ou não com base no estado do tempo.

let nivelPoder = 85;

if (nivelPoder >= 90) {
    console.log("És um Herói de Elite!");
} else if (nivelPoder >= 50) {
    console.log("Estás no bom caminho, jovem aprendiz!");
} else {
    console.log("Precisas de treinar mais!");
}

Módulo 4: Feitiços Reutilizáveis (Funções)

As funções são pequenos blocos de código encapsulados que executam uma tarefa específica. Em vez de repetires o mesmo código várias vezes, crias uma função e chamas-a sempre que precisares.

// Declaração da função
function calcularDano(forcaAtaque, multiplicador) {
    let danoTotal = forcaAtaque * multiplicador;
    return danoTotal; // Devolve o resultado final
}

// Aplicação (Chamada da função)
let golpeFinal = calcularDano(25, 3); 
// golpeFinal agora vale 75

Repara como os valores passados dentro dos parênteses (25 e 3) são os parâmetros que a função interpreta para realizar o cálculo matemático.

Módulo 5: O Domínio do Navegador (DOM e Eventos)

O DOM (Document Object Model) é a ponte mágica que liga o JavaScript ao HTML. Graças ao DOM, o JS consegue ler, alterar ou criar elementos na página em tempo real.
