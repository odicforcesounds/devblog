Docker — Extensive Manual

Run 1 or 50 containers with confidence. Docs: docs.docker.com, Debian install, Compose, Networking, Security.

0 — Install On Debian (Correct Way)

sudo apt update && sudo apt install -y ca-certificates curl gnupg
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/debian/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/debian $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt update && sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker $USER  # re-login; or use sudo
docker run --rm hello-world; docker version; docker compose version
Use Docker's official repo, not stale distro package. hello-world proves daemon + pull work.

1 — First Containers (One, Then Many)

# one nginx on 8080:
docker run -d --name web --restart unless-stopped -p 8080:80 nginx:alpine
docker ps; docker logs -f web; curl http://127.0.0.1:8080
# shell + inspect + stop:
docker exec -it web sh; docker inspect web; docker stop web; docker rm web
# volumes persist beyond rm:
docker run -d --name db -e POSTGRES_PASSWORD=$(openssl rand -hex 16) -v pgdata:/var/lib/postgresql/data postgres:16-alpine

2 — Compose: Multi-Container App (Node + PG + Nginx)

# compose.yaml
services:
  app:
    build: ./app
    restart: unless-stopped
    env_file: [.env]          # 600, never committed
    networks: [front, back]
    depends_on: [db]
  db:
    image: postgres:16-alpine
    restart: unless-stopped
    environment:
      POSTGRES_PASSWORD: ${DB_PASS:?set me}
    volumes: [pgdata:/var/lib/postgresql/data]
    networks: [back]
  proxy:
    image: nginx:alpine
    ports: ["80:80", "443:443"]
    volumes: ["./nginx.conf:/etc/nginx/nginx.conf:ro", "./certs:/etc/certs:ro"]
    networks: [front]
    depends_on: [app]
networks: { front: {}, back: { internal: true } }
volumes: { pgdata: {} }
# run:
docker compose up -d --build; docker compose ps; docker compose logs -f
internal:true on back = DB unreachable from internet even by mistake. Secrets via env_file, never baked into images.

3 — Networking In Depth

bridge (default single-host), user-defined bridge (DNS by name: app→db:5432), host (no isolation, fast), none, overlay (Swarm multi-host), macvlan (real LAN IPs).

docker network create front
docker network ls; docker network inspect front
# attach + test DNS:
docker run --rm --network front alpine nslookup app
docker run --rm --network front nicolaka/netshoot ss -tlnp  # debug toolbox
# publish safely: 127.0.0.1:3000:3000 (localhost only) vs 0.0.0.0:3000 (world)
Compose creates DNS automatically per network. Only proxy publishes ports; app/db stay private. internal:true + no ports = invisible to LAN.

4 — Security (Paranoid But Practical)

# 1. non-root inside:
# Dockerfile: FROM node:20-slim
# RUN useradd -m app && USER app
# 2. read-only + no new privs + caps drop:
docker run -d --read-only --tmpfs /tmp --cap-drop=ALL --cap-add=NET_BIND_SERVICE \
  --security-opt no-new-privileges:true -p 127.0.0.1:3000:3000 myapp:1.0
# 3. secrets, not env -e on CLI (leaks in ps):
echo "sekret" | docker secret create db_pass -  # swarm; compose: env_file 600
# 4. images: pin digests, slim base, scan:
docker scout cves myapp:1.0  # or: grype myapp:1.0 (https://github.com/anchore/grype)
# 5. daemon: /etc/docker/daemon.json {"icc": false, "log-driver":"json-file","log-opts":{"max-size":"10m","max-file":"3"}}
# 6. updates: watchtower pinned minor only, or manual compose pull
Never --privileged, never mount /var/run/docker.sock into untrusted containers, never -p 5432:5432 DB to world. Rootless mode (rootless docs) for extra isolation.

5 — Daily Ops Cheat

docker compose up -d --build; docker compose logs -f --tail=100
docker stats; docker system df; docker system prune -f  # reclaim
docker exec -it db psql -U app -d app
docker compose pull && docker compose up -d  # update
docker backup: docker run --rm -v pgdata:/src -v $(pwd):/dst alpine tar czf /dst/pg.tgz /src

Refs: Engine security, Compose spec, Grype, netshoot.

One network per trust level, one secret per service, least priv always. Compose up, sleep well.
