Wireshark + Nmap — Big Manual

Two tools, one job: see the network. Nmap asks what's there? Wireshark watches what's said? Use only on your own lab/nets or written-authorized scope. Docs: Wireshark docs, Nmap docs, Nmap book.

Rule: scan/capture only what you own or are hired to test. Lab range in examples: 192.168.56.0/24. Never scan strangers, never post pcaps with secrets (chmod 600).

PART A — Wireshark (Read Everything)

A1. Setup + first capture

sudo apt install -y wireshark tshark
sudo usermod -aG wireshark $USER  # re-login; or run with sudo
# GUI: pick interface → capture filter e.g. "host 192.168.56.101" → Start
# CLI: tshark -i eth0 -f "port 443" -w /tmp/lab.pcap
# open: wireshark /tmp/lab.pcap
Capture filter (BPF, kernel) narrows what's saved: host X, port 443. Display filter (Wireshark) narrows what's shown: ip.addr==X && tls. Capture small, display smart.

A2. Display filters you'll use forever

ip.addr == 192.168.56.101
tcp.port == 443 || tcp.port == 80
dns.qry.name contains "example.com"
http.request.method == "GET"
tls.handshake.type == 1          # ClientHello
tcp.analysis.retransmission
icmp
arp.duplicate-address-detected
(data contains "password")       # lab only — then fix the app!

A3. Workflows (follow streams, not packets)

Right-click packet → Follow → TCP/HTTP/TLS Stream. Statistics → Protocol Hierarchy / Conversations / I/O Graph finds top talkers + spikes. Analyze → Expert Info flags retrans/dup-ACK/reset. Profiles: one for DNS, one for TLS, one for VoIP.

A4. TLS case

tshark -r tls.pcap -Y tls -T fields -e tls.handshake.version -e tls.handshake.ciphersuite | head
# no SNI/cipher overlap = fail. Decrypt OWN lab only:
# Edit→Prefs→Protocols→TLS→(Pre)-Master-Secret log → SSLKEYLOGFILE

A5. DNS/DHCP cases

dns.flags.response==0   # queries
dns.flags.rcode != 0     # errors (NXDOMAIN/SERVFAIL)
bootp.option.dhcp==53    # Discover/Offer/Req/ACK
# slow DHCP? filter bootp, check Offer time gap.

A6. Performance + hygiene

Ring buffer, tshark -b filesize:102400 -b files:10 -w cap.pcapng, capinfos, editcap -c 100k big.pcap small.pcap, mergecap. Strip secrets before sharing: tracewrangler.

PART B — Nmap (Map Before You Stare)

B1. Install + first safe scans (own lab)

sudo apt install -y nmap
nmap -sn 192.168.56.0/24              # ping sweep: who is up
nmap -sV -O 192.168.56.101            # versions + OS guess
nmap -sC -sV 192.168.56.101           # default scripts + versions (noisy — lab only)
nmap -p- --min-rate 500 192.168.56.101 # full ports, faster (lab)
Scan types: -sS SYN half-open (fast/stealthy-ish, needs root), -sT connect (no root), -sU UDP (slow, top ports first), -sV versions, -O OS, -A aggressive (= -O -sV -sC + traceroute — loud, lab). Timing -T0..T5 (T4 typical lab, T2 polite).

B2. Pick ports + speed without melting net

nmap --top-ports 100 192.168.56.101
nmap -p 22,80,443,3000,5432 192.168.56.0/24
nmap -F 192.168.56.101                # fast 100
nmap --min-rate 200 --max-retries 2 -T4 192.168.56.0/24  # lab reasonable

B3. Scripts (NSE) — audit, don't attack

nmap --script=vuln 192.168.56.101     # CVE check vs versions (then PATCH)
nmap --script=http-title,http-headers,ssl-cert -p 80,443 192.168.56.101
nmap --script=smb-security-mode,smb-os-discovery -p 445 192.168.56.101
ls /usr/share/nmap/scripts/ | grep -i -E 'http|ssl|smb|dns'
NSE finds candidate issues. Confirm manually, then fix: close port, update, firewall, least priv. Never run vuln/intrusive outside scope.

B4. Output + defend from your own scan

nmap -oA lab-scan 192.168.56.0/24   # .nmap/.xml/.gnmap triple
ndiff scan1.xml scan2.xml            # what changed? new ports = investigate
# Blue response: ufw/nftables deny, update (unattended-upgrades), banners minimal,
# fail2ban, Suricata (https://suricata.io/) alert on sweeps.

PART C — Together: 5 End-to-End Labs

1. New web app: nmap -sV -p 80,443 app → tshark -f "host app and port 443" → curl → Wireshark Follow TLS → fix HSTS/CSP. 2. Mystery slowness: I/O graph spike → Conversations top talker → tcp.analysis.retransmission → MTU/firewall/NIC. 3. Rogue DHCP: bootp two Offers → find MAC → port-shutdown. 4. Cerrt expiry: ssl.handshake.certificates dates + nmap --script ssl-cert → rotate via Certbot. 5. Baseline/drift: weekly -oA + ndiff → ticket every delta.

Refs: DisplayFilters, tshark.dev, Nmap man, NSE docs, Netresec.

Map with Nmap, prove with Wireshark, fix the cause. Packets don't lie — configs do.
