tcpdump — Detailed Field Manual

Capture on your own hosts/nets only, or where explicitly authorized. tcpdump docs: tcpdump.org, manpage, Wireshark wiki for display-filter cousins.

0 — Install, Privileges, First Safe Capture

sudo apt install -y tcpdump wireshark-common
# list interfaces:
ip -br link; tcpdump -D
# first capture (own machine, 5 packets, no DNS noise):
sudo tcpdump -i any -c 5 -nn -q
# read it: timestamps, proto, src > dst, flags/length
Flags you'll use daily: -i interface, -c N count, -nn no-resolve (fast + honest), -q quiet, -v/-vv/-vvv verbosity, -X/-xx hex+ASCII, -A ASCII, -e link headers, -t/-tttt timestamps, -s0 SnapLen full packet, -w file.pcap write, -r file.pcap read, -C/-G/-W rotate.

1 — Options That Matter (Commented)

OptionWhat it does — plain words
-i any/eth0/loWhere to listen. any = all (Linux cooked header); lo proves local app talks.
-nnDon't resolve IPs/ports. Fast, script-safe. Add -q for one-liners.
-c / -C / -G / -WStop after N (-c); rotate file by MB (-C), seconds (-G), keep N files (-W).
-s0Capture full packet (default 262144 modern; old 96 truncated). Use for forensics.
-w/-r/-VWrite/read pcap; -V read file list. Always -w before filtering long jobs.
expressionBPF filter: host/port/net/tcp/udp/icmp/arp/vlan + and/or/not. Kernel-side = cheap.

2 — BPF In 60 Seconds (Filter In Kernel, Win)

sudo tcpdump -i eth0 -nn host 192.168.1.10
sudo tcpdump -i eth0 -nn port 443
sudo tcpdump -i eth0 -nn net 10.0.0.0/8
sudo tcpdump -i eth0 -nn tcp and port 80
sudo tcpdump -i eth0 -nn 'src host 10.0.0.5 and dst port 53'
sudo tcpdump -i eth0 -nn 'not port 22'
# combo: web to one host, no noise:
sudo tcpdump -i any -nn -s0 'host 192.168.56.101 and (port 80 or port 443)'
Quote complex filters. and binds tighter than or — parenthesize. Test with -d (dump compiled BPF).

3 — Use Cases (Copy-Paste, Lab IPs)

A. Is my app even sending?

sudo tcpdump -i lo -nn -c 20 port 3000
# see SYN/SYN-ACK/ACK then PUSH. No packets = app binds wrong iface (check 127.0.0.1 vs 0.0.0.0).

B. DNS lying?

sudo tcpdump -i any -nn port 53 -vv
# A? api.example.com, answers, NXDOMAIN, retries. Pair with: dig +trace; systemd-resolve --statistics

C. TLS handshake or fail?

sudo tcpdump -i eth0 -nn -s0 'host api.example.com and port 443' -w tls.pcap
# open tls.pcap in Wireshark (https://www.wireshark.org/): ClientHello → ServerHello → cert → alert?
# tcpdump shows sizes/timing; decrypt only with own keylog (SSLKEYLOGFILE) in lab.

D. DHCP drama

sudo tcpdump -i eth0 -nn -vvv port 67 or port 68 -e
# Discover/Offer/Request/ACK. No Offer = server/cable/VLAN; slow = rogue server race.

E. Who ARPs? Spoof hunt (defense)

sudo tcpdump -i eth0 -nn -e arp
# one IP flapping MACs = investigate. Harden: static ARP for gateway (temp), Dynamic ARP Inspection on switch.

F. Ping/latency truth

sudo tcpdump -i eth0 -nn icmp and host 8.8.8.8
ping -c4 8.8.8.8  # match echo req/reply, dupes = loop, no reply + ! = firewall

G. HTTP without body vs with body

sudo tcpdump -i any -nn -A 'port 80 and host 192.168.56.101'   # headers readable (http only!)
sudo tcpdump -i any -nn -s0 -X 'port 80'  # hex+ASCII for binary edge cases

H. Packet loss / retransmits

sudo tcpdump -i eth0 -nn -tttt 'host DB and port 5432' | grep -i 'retrans\|dup\|out-of-order'
# many retrans = MTU/congestion/NIC offload. Try: ping -M do -s 1472 host (MTU probe).

I. Save now, filter later (forensics pattern)

sudo tcpdump -i eth0 -s0 -C 100 -W 10 -W 10 -w /var/cap/lab-%F-%T.pcap -G 300 'not port 22'
tcpdump -r /var/cap/lab-*.pcap -nn 'host X and port 443' | head
# move to Wireshark/tshark (https://tshark.dev/) for deep dive.
Only capture what you're allowed. Full packets may contain passwords/tokens — chmod 600 *.pcap, encrypt at rest, delete when done. Never post pcaps with secrets.

4 — Reading Output (Flags Demystified)

IP 10.0.0.5.54321 > 10.0.0.10.443: Flags [S], seq 0, win 64240, length 0
# S=SYN start, P=PUSH data, F=FIN end, R=RST abort, .=ACK. [S.] = SYN+ACK.
# seq/ack track streams; win = buffer; length = payload bytes.

5 — Performance & Safety

Long jobs: -nn -q -s0 -C/-G/-W -w, BPF narrow, nice + ring buffer (--buffer-size), drop counters via -v end stats. Rotate, compress (gzip), ship to analysis host. Pair with tshark -r x.pcap -T fields for CSV, capinfos.

Refs: tcpdump man, pcap-filter (BPF), Wireshark display filters, Netresec blog (pcap craft).

Capture small, filter early, write always, read with Wireshark. The packet never lies — configs do.
