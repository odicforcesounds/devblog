FreeBSD Basics: Some notes

Add New User Account

useradd

Remove Old User Account

rmuser username

Update information about user (including pass)

chpass username

Create new group

pw groupadd groupname

Add user to new group

pw groupmod groupname -M user

vi & ee

/bin/sh & /bin/csh

One correction before you copy and paste

On FreeBSD the interactive way to create an account is adduser, and the scriptable way is pw useradd. The bare useradd belongs to Linux, and it is the habit that most of us bring from there. Two commands, two different systems, and a page of notes is exactly where that difference should be written down.

Why these files matter

FreeBSD separates what the base system needs from what the packages need, and the separation is visible in the paths. The base lives in /etc, the ports and packages live in /usr/local, and each one has its own place for configuration.

/etc/rc.conf is the list of services that start with the machine. One line per service, written by hand, read at boot. No magic tool that rewrites it behind your back, which is a blessing the first time something refuses to start and a curse the first time you forget what you wrote.

/boot/loader.conf is the same idea one level lower. What it contains is loaded before the kernel has a chance to ask anything, so a mistake there can leave the machine without a network or without a console. Change one line, reboot, check, then change the next.

Small tools, long life

vi and ee are not the best editors in the world. They are the ones that will be there when the network is down and the only thing that works is the console. The same is true of /bin/sh and /bin/csh: they are not fashionable, they are present.

A BSD guy is dumb in the way a hammer is dumb. It does one thing, it does it the same way every time, and it never asks to be updated before it can hit a nail.
