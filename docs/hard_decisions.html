Hard decisions

I don’t like to expose criminal activity against my sites, but when is annoying, I have no other choice.

I really try to redirect attacks to my sites to this page, but after more than 1 week, I decided to redirect all attacks to some police service, while that is too strong, I decide to redirect them to my own GitHub repository.

This decision is based on the false idea of having a lot of visit.

KISS: Keep it Stupid Simple

Click using the mouse, don’t try to use tools to attack this sites.

There is nothing more than what is exposed: No Databases, No Users, No Emails, No dedicated-servers, etc..

Pure text, sometimes backgrounds and music.

What the decision was not about

It was not about revenge, and it was not about safety. Nobody who attacks a static page is going to be found, and nobody who runs a blog is going to become an investigator because of it. The decision was about attention: how much of my day belongs to a machine that was not invited.

For a week I redirected the noise to a page that explains the attacks. The idea was generous, almost pedagogical: read what you are doing, maybe you will recognise yourself. It did not work, because the traffic that arrives is not looking at the page, it is looking at the answer code.

Then the answer changed

Redirecting to a police service would have been theatre, and theatre with consequences for nobody. Redirecting to my own repository is a smaller move with the same message: this is everything I have, it is public, and there is nothing behind the door you are trying to open.

After that, the noise is still noise, but it is a noise I chose. That is the only part of the situation I can control, and controlling it was worth more than winning an argument with a script.

The KISS of a static site

No database means no injection. No users means no stolen passwords. No email list means no leak. No dedicated server means no server to compromise beyond a directory of files that any browser can download anyway.

It is not a security architecture, it is the absence of one, and the absence is the point. The smaller the surface, the less there is to decide.
