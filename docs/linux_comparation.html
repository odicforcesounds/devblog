Comparar Distros Linux

Comecei a usar GNU Linux com o Slackware 7.1, com o primeiro CD de instalação. Foi um tempo difícil, para ter o servidor X a funcionar, mas depois de quase 1 ano a explorar e testar, finalmente consegui. Depois disso, comecei a ver outras distros populares, só para ver a diferença entre elas. Talvez só os sistemas BSD me façam pensar que algo era mesmo diferente entre elas, mas naturalmente cada distro segue alguma especificação: como se parece, que pacotes tem já instalados, as formas diferentes de a instalar, etc.

Há uns anos li o livro do LFS e decidi testar o Gentoo.

O Gentoo é o Melhor se nos focarmos em quanta RAM usa e como essa RAM é libertada quando as aplicações terminam. É espantoso. É a melhor característica e o melhor resultado de ter uma distribuição GNU Linux baseada em fonte como o Gentoo. Sobre o tempo gasto no processo de compilação: se fores uma pessoa que tem mais computadores para usar e tem vida fora daquela sala cheia de computadores, o Gentoo não é assim tão difícil. Começas a compilar hoje e amanhã o teu sistema pode estar pronto a usar. Se actualizares o sistema uma vez por semana, o processo de espera pode ser menor. Naturalmente há pacotes que te pedem um «super computador» para compilar em menos de 24 horas, mas tens alternativas que consomem menos tempo de compilação, já que o Gentoo tem uma forma de instalar pacotes pré-compilados como o Rust, o Firefox, o Chromium e outros, que consomem muito tempo de compilação. Outro aspecto de que gosto no Gentoo é que usa OpenRC, que o Slackware também usa, enquanto a maioria das distros mudou para o Systemd.

Neste momento estou a testar o Arch Linux, que usa Systemd por predefinição e consome um pouco mais de Memória. Por exemplo, a instalação mínima do Debian e do Arch usa cerca de 200/300MB sem usar software extra. Só iniciamos sessão e abrimos o HTOP para ver quanta memória está a ser usada, embora pudéssemos usar o comando free -h, só para ver quanta memória o sistema está a usar. No mesmo exemplo com Gentoo, vemos o resultado do mesmo comando, algo como: 70MB. Mas quando compilamos software, consome um pouco menos do que qualquer outro software pré-compilado.

Algo que não percebi durante muito tempo é que o Arch tem os repositórios AUR, que nos permitem compilar software a partir da fonte. E isso é sempre uma diferença enorme. Adoro usar o NChat, um software de conversação de terminal para Telegram e Whatsapp, e quando o compilo usa cerca de 200MB, enquanto instalado de fontes pré-compiladas consome quase 500MB.

Infelizmente, se um utilizador não actualizar o Gentoo todos os meses, terá um problema grande grande grande ao tentar actualizar, ao fim de alguns meses ou anos. Nesse aspecto, o Gentoo é o Mau, enquanto o Debian é o Bom, e mesmo que a compatibilidade de software seja grande, o Arch Linux é o Feio.

O Gentoo é mesmo bom, se usares a pequena lista de software que o Gentoo tem. Sim, sim, é pequena se a comparares com o Arch ou o Debian. Fico muito contente por ver como o Arch inclui pacotes novos que não estão nos repositórios principais. Um dos pacotes que gosto de usar é o Tui-Journal, uma aplicação Rust, ou o wiki-tui. Ambos já estão incluídos nos repositórios principais do Arch, enquanto no Debian ou no Gentoo precisamos de instalar o Rust para compilar estes pacotes.

Apaixonei-me pelo Arch. Infelizmente usa Systemd, mas deixando de lado esse pequeno problema, adoro-o mesmo.

Comparing Linux Distros

I start using GNU Linux with Slackware 7.1, with the first installation CD. It was a hard time, to have the X server working, but after almost 1 year exploring and testing, I finaly could. After that, I start checking others popular distros, just to see the difference between them. Maybe only BSD systems make me think that something was really different from each others, but naturally each distro follow some specification, on how it looks, what packages have already installed, the different ways to install it, etc.

Years ago, I read the LFS book and I decide to test Gentoo.

Gentoo is the Best if we are focusing how much RAM uses and how this RAM is freeded when applications are terminated. Is amazing. This is the best feature and result of having a Source-based GNU Linux distribution like Gentoo. About time consuming in the compilation process: If you are a person that have more computers to use and have a life outside of that room full of computers, Gentoo is not so hard. You start compiling today and tomorow your system may be is ready to use. If you update your system once per week, the process of waiting can be less. Naturally there are some packages that ask you a “super computer” to compile them in less than 24 hours, but you have alternatives that consume less time of compilation, while Gentoo, already have a way to install pre-compiled packages like Rust, Firefox, Chromium and others, that consume a lot of compilation time. Another aspect I like in Gentoo, is that it uses OpenRC, which Slackware use too, while the majority of distros, change to Systemd.

Right now, I am testing Arch Linux that use Systemd by default and it consume a little bit more Memory. For example, the minimal instalation from Debian and Arch, use about 200/300MB without using some extra software. We just login and we open HTOP to see how much memory is using, while we could use the free -h command, just to see how much memory the OS is using. The same example using Gentoo, we will see the result of the same command, something like: 70MB. But when we compile software, it will consume a little bit less than any other pre-compiled software.

Something I didn’t realize for long time, is that Arch have the AUR’s repositories, which enable us to compile software from the source. And is always a big big difference. I love to use NChat, a terminal chat-software for Telegram and Whatsapp, and when I compile it it use about 200MB while when installing from pre-compiled sources, it consume almost 500MB.

Sadly if a user don’t update Gentoo every month, the user will have a big big big problem when trying to update, after some months or years. By this aspect, Gentoo is the Bad while Debian is the Good, even if software compatibility is big, Arch Linux is the Ugly.

Gentoo is really nice, if you use the small list of software Gentoo have. Yes, yes, is small if you compare it to Arch or Debian. I am really happy to see how Arch include new packages that are not in the main repositories. One of the package I like to use is Tui-Journal, a Rust application or wiki-tui. Both are already included in the main Arch repositories, while in Debian or Gentoo, we need to install Rust to compile this packages.

I fall in Love with Arch. Sadly it use Systemd, but putting away this little problem, I really love it.
