📖 Core concepts cheat-sheet (click to open)

BPM

Beats per minute. Classical 40–180 (fluid), Doom 60–80, Rock 110–140, Thrash 180–220, Techno 120–135, Psytrance 138–148, Hitech 170–200, Black metal blast 200+.

Scales

Classical: major/minor + modes. Blues: minor pentatonic + ♭5 "blue note". Metal: Phrygian, Locrian, harmonic minor. Psytrance: Phrygian dominant for that desert-snake feel.

Timbre

Distortion = clipped guitar wave. Acid = resonant low-pass sweep (TB-303). Supersaw = stacked detuned synths. 909 kick = sine pitch-drop + click.

Form

Sonata (exposition-development-recap), Verse-Chorus, 12-bar blues, Rave build-drop, DJ-mixable 8-bar loops, Black-metal tremolo walls.
