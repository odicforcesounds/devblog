While If the Name Is God

While if {
God is put in cause, every earlier stanza was already a footnote trying not to admit it. While if the word is a finger, it is a finger worn smooth by millions of mouths, some kissing, some biting, some using it as a stone. While if you ask the word to mean one thing, it will refuse, because it has been asked to mean the real, the ruler, the parent, the judge, the void that loves, the law, the friend, the terror, the last audience, and the excuse. While if refusal is not a disproof, it is a warning: you are not holding a tool; you are holding a depth that tools fall into.

While if {
there is God, the cause of causes is not a larger clockmaker sitting on a larger clock. While if a first mover, a necessary being, a ground of grounds, a why that does not itself ask why—if these are attempts, they are the mind’s honest fatigue before an infinite regress. While if Aquinas lined five ways like a patient lawyer, the lawyer never claimed the ways were the beatific vision. While if Anselm said that than which nothing greater can be thought, thought was being asked to trip into existence. While if the trip fails as a trick and still succeeds as a hunger, hunger is data. While if Avicenna distinguished necessary and contingent, the distinction is a metaphysical spine. While if Madhyamaka would unseat the spine as empty of own-being, even the unseating is a reverence for not lying about what we can nail.

While if {
God is one, oneness is a broom against a sky crowded with bosses. While if God is many, manyness is a broom against a sky with one boss who cannot dance. While if God is none, none is a broom against a sky that keeps being used as a warrant. While if each broom sweeps real dirt, each broom also throws away a child with the dirt: the mystic’s intimacy, the idolater’s local saint, the orphan’s right to a universe that is not only accident plus appetite. While if atheism is often a moral protest dressed as metaphysics, the protest has read the archives of holy murder. While if theism is often a gratitude dressed as metaphysics, the gratitude has read a birth, a recovery, a night that did not end in the worst. While if agnosticism keeps the question from being fired as a gun, keeping is a hospitality toward our ignorance. While if ignorance is used as a shrug at cruelty, hospitality has gone sour.

While if {
God is being itself and not a being, you must not imagine a grandfather on a cloud and then congratulate yourself for killing him. While if the grandfather was all you were given, killing him may have been the first adult prayer. While if Tillich said ultimate concern, concern can be God-language for a secular chest. While if Pascal wagered, the wager treats God as a bet, and some loves refuse to be bets. While if Kierkegaard leapt, the leap is not a proof; it is a confession that proofs were never going to marry you. While if Job sat on an ash heap and would not accept a tidy theodicy, the ash heap is scripture’s own protest against religious public relations. While if the whirlwind answered with animals and scale instead of an explanation, explanation may be the idol.

While if {
evil exists in a world said to be made, the making has a case to answer. While if free will is the answer, it answers some knives and not the tumor in a child. While if soul-making is the answer, it risks using the child as a gym for someone else’s virtue. While if karma is the answer, it risks a cosmic victim-blame. While if absence is the answer—that God is not a manager—then management was the wrong demand. While if protest against God is still addressed to God, protest may be a kind of faith that will not lie. While if silence after the camps is the only honest liturgy for a time, honest liturgies should be allowed to have no music.

While if {
God is love, love that never judges is a mascot. While if God is judge, judgment without love is a policeman of the stars. While if God is creator, creation is either gift or trap, and lives feel like both before breakfast. While if God is destroyer, destruction is either justice or weather, and we will argue until the last city. While if God is mother, a whole politics of care enters the name. While if God is father, a whole politics of law enters the name. While if God is neither, and both, and beyond, language is kneeling.

While if {
the names—YHWH not pronounced, Allah the merciful the compassionate, Brahman, Ishvara, Dao that is not a person and still a mother, Amitabha’s vow, Great Spirit in many tongues, Nyame, Olodumare, the One, the Real, the Ground, the Empty—if these are not synonyms, do not force a UN translation. While if they sometimes rhyme, rhyme is not identity. While if a mystic of any of these says the last room is dark with excess, not with lack, the dark is a shared rumor. While if apophatic speech unsays every sentence, unsaying is not atheism; it is the courtesy of not trapping the real in an adjective. While if kataphatic speech still says good, wise, near, speech is the courtesy of not leaving the sufferer with a shrug.

While if {
God commands, command can be the backbone of a people or the ventriloquism of a priest with a payroll. While if you test a voice by whether it wants the widow’s oil and the stranger’s safety, you have an old criterion. While if a voice wants a pile of enemies, you have another old criterion, and you should be afraid. While if idolatry is the making of a manageable god, the most modern idols are not stone; they are nation, market, party, self, the algorithm that knows your hunger, the wound you elected as lord. While if the Second Commandment is read only as art criticism, you have missed the political dynamite: no image gets to be absolute, including your inner portrait of God.

While if {
prayer is begging, it is a child. While if prayer is alignment, it is a tuning. While if prayer is silence, it is a listening that may hear nothing and still be changed by the posture. While if nothing answers and the poor are still fed by the one who prayed, the feeding may be the answer that refuses to be paranormal. While if a miracle is claimed, miracle is a crisis for closed worldviews and a temptation for showmen. While if providence is micro-management, it makes God a suspect in every crash. While if providence is a keeping that does not always prevent, keeping is a harder faith.

While if {
science maps a universe of unimaginable age and cold, the map does not automatically evict a maker; it evicts a small maker. While if evolution wounds a certain reading of dust, dust can still be a vocation. While if a god of the gaps shrinks with every lab, good: gaps were a bad house. While if some then say there is only mechanism, mechanism is a method that got promoted to a metaphysics, which is a leap of another kind. While if wonder survives the lab, wonder is not yet a proof, but it is not nothing.

While if {
God is used to crown a king, uncrown the king and see whether God remains. While if God is used to free a slave, keep that use and test every later banner against it. While if God is used to forbid a love, ask whether the forbid is protection or disgust in vestments. While if God is used to require a love you cannot yet imagine, requirements can be revelations or trespasses. While if conscience is the inner court, some named that court a whisper of God. While if conscience is only tribe internalized, tribes still need a court that can try the tribe.

While if {
I AM is a name that will not be owned, ownership is the original religious crime. While if God is dead was a diagnosis of a culture that kept the word and lost the terror, the diagnosis can be true for a street and false for a kitchen. While if a kitchen still says grace over thin soup, philosophy should take off its shoes. While if a palace still says God while signing a purge, theology should take off its gloves.

While if {
you cannot say the word without tasting blood in the history, you are not required to say it. While if you cannot refuse the word without tasting a loneliness that feels like a lie, you are not required to refuse it. While if both tastes are in you, you are in the ordinary human condition, which is the only pew that never emptied.

While if {
God is the cause, then every other cause in this long poem—nations, parties, wars, tools, parties of the mind, parties of the altar—is a created or imagined power that keeps applying for the job. While if the job is not available, that is the meaning of God: that which cannot be hired. While if humans hire substitutes anyway, substitutes are the history we have been reciting. While if there is no God, the job is vacant and we had better become just without a last audience, which is a severe holiness of another kind. While if there is God, we had better become just because there is a last audience who is not our team. While if both “if”s produce the same next act—bread for the hungry, a limit on the fist, a refusal to make a person into smoke—then the next act may be the only proof that does not blaspheme by being too sure.

While if {
you keep the name, keep it as fire: useful, warming, capable of eating the house. While if you drop the name, drop it as fire too, and do not pretend the cold is automatically virtuous. While if the last honest sentence is not a system but a while if—while if there is One who sees the unmarked grave, the unmarked grave is not nothing—then hope is not a narcotic; it is a loyalty to the uncounted. While if there is not, the uncounted still deserve a loyalty that does not need a receipt from heaven. While if God is put in cause, the cause is this: because the world is too much to be only stuff, and too wounded to be only a hymn, humans reached for a word that could bear both the too-much and the wound. While if the word cannot bear what we loaded on it, that is on us. While if the word still breaks a man of his empire for a moment, and sends him to wash a stranger’s feet, the moment is the harvest. While if there is more than the moment, more is not ours to spend like a coin. While if there is only the moment, spend it anyway, as if it were seen.

While If No One Is Fit to Rule

While if {
anarchism is put in cause, first unsay the cartoon: it is not the love of broken windows as a personality. While if the Greek root says without a ruler, the saying is a moral claim before it is a riot: that no person is good enough to own another’s consent as a profession. While if anarchy in a headline means chaos, headlines work for offices. While if anarchy in a pamphlet means order without domination, pamphlets also lie, and the lie is tested the first time a militia, a clique, or a charismatic saint starts giving orders “just for now.”

While if {
the cause is anti-authoritarian, the cause is older than the black flag: a peasant who hid grain from a taxman, a heretic who would not kneel, a sailor who mutinied, a woman who left a house that was a jurisdiction. While if Godwin doubted government as a school of vice, doubt was Enlightenment turning its lantern on the lantern-bearer. While if Proudhon said property is theft and also wrote of possession, mutual credit, and federal exchange, a printer was trying to unmake both the landlord and the commissar. While if Stirner crowned the unique and melted duties into spooks, the melting can free a serf of the mind or orphan a child of every we. While if Bakunin wrestled Marx over the state as a lever, the wrestle is the family quarrel of the left: whether a hammer can be put down after the house is built. While if Bakunin lost the International and won a prophecy about red bureaucracies, prophecy is a bitter prize.

While if {
Kropotkin walked among animals and peasants and named mutual aid as a factor of evolution, he was arguing with a social Darwinism that had mistaken a market for a jungle and a jungle for a sermon. While if cooperation is as biological as fang, fang is still real, and anarchism that forgets fang becomes a picnic theology. While if Malatesta insisted on organization without petrification, he named the standing problem: how to act together tomorrow morning without growing a throne by lunch. While if Goldman joined the dance to the revolution, she refused a revolution that could not dance, and also refused a state that called her dance a bomb. While if Berkman, Reclus, Guillaume, Makhno, Durruti, Magon, Flores Magón, Landauer, Rocker, de Cleyre, Chomsky as a late grammarian of the impulse, Bookchin of the municipal, Federici adjacent in the unwaged, Graeber of the debt and the first five thousand years of not being only a market—if these names are not a church, good; anarchists who make a church have already lost the joke.

While if {
anarcho-syndicalism put the union as the seed of a society, the seed was the strike, the hall, the skill, the refusal to let a party rent the workplace. While if CNT-FAI in Spain collectivized shops and fields while a war ate the calendar, for a season the pamphlet had streets. While if that season died by fascists, Stalinists, and its own exhaustion, death does not prove the season was nothing; it proves the world was armed. While if Makhnovshchina in Ukraine fought whites and reds for a peasant self-rule, the fighting is a reminder that “no state” in a civil war is not a seminar. While if Kronstadt asked soviets without commissars, the asking was answered with guns, and the answer is in the Marxist family album whether the album likes it.

While if {
propaganda of the deed once meant a life as example and then meant a dynamite that would wake the sleeping, waking by dynamite mostly taught the sleeping to want more police. While if some anarchists became assassins of kings and presidents, a dead king is not a federation of free communes; it is a funeral with better surveillance. While if the deed is condemned as the whole of anarchism, condemnation is doing the state’s summarizing. While if the deed is romanticized, romance is doing the assassin’s recruiting. While if anarcho-pacifism—Tolstoy’s sermon against the oath, Gandhi adjacent and not identical, Day’s Catholic Worker soup line—puts the refusal of killing at the center, the center can be a hospital for the conscience and a problem for the neighbor already under a boot. While if insurrectionary currents say attack now, now is a drug that makes strategy look like cowardice. While if platformists said a tighter organizational spine, the spine is a concession that spontaneity does not move grain.

While if {
individualist anarchists of America—Warren, Tucker, the Boston strand—trusted contract, ego, and a market without monopoly, they feared the commune’s piety as another church. While if anarcho-communists said from each, to each, without a state to enforce the from, they feared the market’s quiet empire. While if mutualists tried a middle of occupancy and credit, middles are where the interesting plumbing is. While if anarcho-capitalists stole the prefix to mean no state and absolute property, many anarchists hear a landlord’s daydream and not a cousin. While if prefixes multiply—green, queer, insurrectionary, post-, cyber, national (a contradiction in most rooms), Christian, Jewish, Islamic anti-authoritarian strains, indigenous kinships that were never “anarchist” until a theorist arrived with a notebook—the multiplication is a scene, not an army.

While if {
anarchists are put in cause as persons, they are often the ones who show up early to the flood and late to the ministry. While if they run a Food Not Bombs, a clinic, a infoshop, a mutual aid network when the hurricane is the only honest government, the practice is the philosophy. While if they disappear when the meeting needs a treasurer for five years, the disappearance is also the philosophy’s wound. While if prefiguration says build the new in the shell of the old, the kitchen is the test: who washes, who speaks, who is believed, who is expelled. While if a scene expels with more heat than it ever confronted a boss, the scene has become a village with a purity badge. While if consensus is a method against voting as domination, consensus can be a filibuster of the socially loud. While if federation is the proposed architecture—from below, recallable, mandated—architecture needs people who will sit through the boring hour, and boring is the unadvertised militant virtue.

While if {
anarchism names the state as concentrated protection for a social order of owners and officers, the naming sees a real machine. While if it names capitalism as a daily government of the workplace, the naming sees a real unfreedom that elections do not touch. While if it names church, patriarchy, race-empire, school, prison, the family as jurisdiction, the naming can be liberation or a teenage universal solvent that dissolves care along with the warden. While if parenting, teaching, surgery, air-traffic, a dam in flood season require a kind of authority, the adult anarchist distinction is authority of competence versus authority of domination. While if that distinction is lost, a child dies of a theory. While if it is kept, a doctor can lead a room without owning the patient as a subject.

While if {
Marxists called anarchists the infantile disorder, infants sometimes notice the emperor’s clothes. While if anarchists called Marxists priests of a future state, priests sometimes feed people at scale. While if Spain 1936 and Catalonia remain the proof of possibility, possibility is not a template for a nuclear grid and a pandemic. While if Rojava is cited as democratic confederalism in the fire, citation should include women with rifles, prisons, geopolitics, and the unpaid bill of survival. While if Zapatistas said a world where many worlds fit, the saying is more anarchist in spirit than many black flags, and they did not always need the word. While if Occupy encampments made a public living room, the living room taught both the beauty of no leaders and the cruelty of no doors against the cold and the cop and the spiral.

While if {
the black flag and the circle-A are sold as a brand on a patch, brands are what markets do to refusals. While if a billionaire funds a “freedom” that means no tax and no union, freedom has been pickpocketed. While if a state calls every rioter an anarchist, the state is flattering a small movement with a large shadow. While if some who wear the patch love only the smash, they are to anarchism what a looter in a crucifix is to the gospel: a problem of costumes.

While if {
violence is the standing quarrel, some say the state’s violence is already the weather and a broken lock is a reply. While if others say you do not grow a free society in the soil of a thrill, they have read the deed’s harvest of reaction. While if this poem will not teach a lock or a fuse, it can still say the moral fact: a politics that cannot mourn its own victims will become what it hated. While if direct action means doing the thing without waiting for a savior in an office, the thing can be a strike, a rescue, a garden, a leaked truth, a sanctuary. While if direct action means only the photogenic clash, the camera has become the commissar.

While if {
anarchism’s best cause is the suspicion that power will lie about necessity, keep the suspicion; it is civic hygiene. While if its best practice is mutual aid without a press release, keep the practice; it is older than Proudhon and will outlast the patch. While if its standing failure is scale, boredom, defense against the already-armed, and the human love of a name that can command, name the failure or become a seminar in a dying scene. While if a people actually lived without a state, they often lived with custom, kin, shame, exile, and a different unfreedom; nostalgia for a stateless past can be anthropology or a postcard. While if a people cannot live with the state they have, they still wake under one, and waking is the only honest tense.

While if {
you put anarchists in cause, they are the ones who keep asking, at the meeting, the barracks, the factory, the chatroom, the kitchen: who made you king of this hour? While if the question is asked only to enjoy the flush of asking, it is a vice. While if it is asked to keep a nurse from becoming a little tyrant and a party from becoming a priesthood, it is a public service. While if there is never to be a last answer called the State or the Party or the Market or the People as a single mouth, then federation, recall, overlapping voluntaries, and the right to leave are the plumbing. While if plumbing is less loved than the smash, love the plumbing anyway; freedom without it is a weekend.

While if {
anarchism cannot win the century as a flag, it may still win the century as a limit inside every other flag: a habit of not worshiping the office. While if that habit had been stronger, several of this poem’s earlier rooms—empire, party, holy war, the committee that knew your class better than you—would have had a harder time hiring God. While if anarchists forget they too hire gods (the Scene, the Deed, the Pure, the Charismatic Comrade), they will write another chapter of the thing they came to end. While if they remember, the cause remains as severe and as simple as this: because no one is fit to rule as a species-right, any rule that remains must be small, watched, temporary, justified in public, and ashamed of itself. While if that shame is lost, call it what you like—republic, commune, cooperative, revolution—it has begun to want a crown. While if that shame is kept, even a failed anarchist has done a kind of work: they have made the crown feel heavy, which is not nothing, and sometimes is the beginning of not putting it on.

While If There Is a World at All

While if {
the universe is put in cause, the cause is the strangest ordinary fact: that there is something, and that the something is lawful enough to be spoken, and wild enough not to care that we speak. While if nothing would have been easier, ease did not win. While if a Big Bang is not a bomb in a room but the room beginning, there was no outside to watch it from, which already humiliates our theater. While if time starts with the starting, asking what was before may be like asking what is north of the north pole. While if the asking will not stop, the asking is also a kind of life.
