O Gentoo era baseado em OpenRC, mas neste dia duvido.

A usar a ISO Minimal para instalar Gentoo e a seguir o Handbook com o navegador Links. A propósito, podes entrar em #Gentoo em irc.libera.chat para pedir ajuda, mas não podes entrar no fórum se não estiveres a usar Gentoo. Vão fazer-te uma pergunta que só quem usa Gentoo sabe responder. Portanto, precisas de ter já uma máquina Gentoo instalada, senão não te consegues registar no fórum deles.

Gosto de misturar coisas que não precisam de organização, como o meu blog ou os meus sites. Mas para leitura técnica prefiro mesmo uma leitura passo a passo, sem informação a mais a criar confusão. É a principal razão por que não gosto da documentação das linguagens de programação. Elas «falam» de coisas que podem ser úteis de falar quando o utilizador já conhece as bases, enquanto a maioria das linguagens de programação do mundo partilha informação a mais e, por isso, torna-se mesmo difícil começar. (pelo menos na minha opinião, mas como sou um pouco estúpido, posso assumir que o problema é meu e não da documentação deles) ... enfim:

O Handbook do Gentoo era fantástico há uns anos, mas hoje é uma Leitura Horrível e Nojenta. Quer dizer, sempre favorecem os sistemas OpenRC, enquanto durante anos o Handbook principal estava focado em OpenRC; hoje é mais sobre SystemD do que OpenRC. Podiam criar um Handbook separado para cada um, mas misturam tudo num só. De facto, parece que mudaram para SystemD e ignoram OpenRC. Isto é sobre a minha experiência. Nos últimos dias estava quase a instalar Gentoo, mas percebo que o Handbook se tornou tão confuso que eu conseguiria fazer melhor. Naturalmente não sei tanto como eles, mas sim... misturar OpenRC e SystemD num único Handbook é uma loucura, ainda mais quando sabemos que o OpenRC não desenvolveu alternativas ao SystemD e, por isso, mesmo com a flag USE="-systemd" vamos precisar de instalar algumas bibliotecas e software do SystemD. Neste ponto, o Gentoo tornou-se uma porcaria para mim. Infelizmente, porque na minha opinião foi durante anos a melhor distro a gerir o uso de memória, muito melhor do que qualquer outra.

Sabes, se o Gentoo se preocupasse mais em organizar a documentação do seu próprio Handbook, prepararia a documentação que funciona, qualquer que seja o nível de especialidade do utilizador, e depois acrescentaria ligações para a alternativa à escolha principal. Podiam criar um Handbook para OpenRC e apontar os mesmos passos para SystemD, ou falar das alternativas que existem para instalar o Kernel com a consideração básica (qualquer que seja a escolha do utilizador, este método funciona), mas isso não é assim tão claro nos dias de hoje.

Gentoo was based on OpenRC but this day I doubt it.

Using the Minimal ISO to install Gentoo and following the Handbook using Links Web Browser. By the way, you can join #Gentoo at irc.libera.chat to ask help, but you cannot join the forum if you are not using Gentoo. They will make you a question that only those who are using Gentoo, can know the answer. So, you need to have some Gentoo Machine already installed, else you cannot register into their forum.

I like to mix things that don't need organization, like my blog or sites are. But for technical reading, I really prefer a step by step reading, without too much information to create confusion. That is the main reason I don't like Programming language documentation. They "talk" about stuff that can be useful to talk, when the user already know the basis, while most programming languages in the world, share too much information and therefor, becomes really difficult to start. ( at least on my opinion, but since I am a little stupid, I ca assume that the problem is on me, not on their documentation ) ... anyway:

Gentoo Handbook was really awesome few years ago, but these days is Horrible Reading and Discusting. I mean, they always favorite OpenRC systems while for years, the main Handbook was focused on OpenRC, today is more about SystemD than OpenRC. They could create a separated Handbook for each, but they mix all in one. In fact, it looks like they switch to SystemD and Ignore OpenRC. This is about my experience. Last days I was about to install Gentoo but I realize that the Handbook become so confusion that I could do better. Naturally I don't know much as they do, but yeah.. mixing both OpenRC and SystemD in one single Handbook is crazy, even more when we know that OpenRC didn't develop alternatives to SystemD and therefor even if we USE="-systemd" Flag, we will need to install some SystemD Libraries and software. So, at this point, Gentoo become Shit to me. Sadly, since in my opinion was for years, the best Distro that could manage much better than any other distro, Memory usage.

You know, if Gentoo cares more about organizing the documentation of it's own Handbook, it would prepare the documentation that would work, what ever the level of expertise the user is and then, add links to what is the alternative of the Main choice. So, they could create a Handbook for OpenRC and point the same steps for SystemD or to talk about which alternatives exist to install the Kernel, with the basic consideration (what ever is user choice, this method will work), but that is not so clear these days.
