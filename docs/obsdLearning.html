Descobri que o OpenBSD pode ser o meu sistema operativo principal

Caso queira usar este sistema como Firewall, devia tentar usá-lo sem instalar software extra, para ter a certeza de que o meu «Router» está seguro. Mas, ao ler a documentação do OpenBSD, vejo que é possível usar este sistema como Desktop com Firefox e muito outro software que uso normalmente em Linux. De facto, posso até emular uma máquina Linux dentro do OBSD e correr as aplicações de que gosto que não estão no OBSD, para lhes aceder com facilidade. A popularidade deste sistema não é grande, e eu não procuro popularidade, mas estabilidade. Por omissão, se tentares usar o Firefox o sistema fica lento que dói e podes perguntar: «Mas porquê?». A resposta está nas configurações predefinidas com que o OBSD corre. Se as mudares, terás um «sistema rápido», sem ser lento que dói. Fica menos seguro? (provavelmente fica, mas se não estiveres a servir nenhum serviço público, não é grande problema mudar essas configurações.) Então comecei a tentar usar o 'vi' sem instalar o 'vim'. É um pouco estranho, já que há algumas diferenças, mas se souberes jogar com o Vim, o 'vi' será um pouco diferente, mas não muito. Não há navegador por omissão, por isso preciso de instalar um pacote mínimo, como o 'w3m' ou o 'elinks', que são os meus navegadores favoritos para o terminal. Com isto em mente, consigo configurar uma máquina para ser uma firewall dedicada, tendo outras que não são, mas Desktops. Infelizmente, pelo menos para mim, preciso de ter uma máquina dedicada a usar Linux, já que a aplicação Cloudflared para criar um túnel entre o meu servidor pessoal e os servidores da Cloudflare não corre em OBSD nem em FBSD. Nesse ponto, mantenho o sistema Linux mais acessível do mundo, que é (na minha opinião, o Debian). Posso corrê-lo numa VM ou numa Máquina dedicada. Para isto, prefiro mesmo dedicar uma Máquina, já que consigo correr todo o software necessário sem «hackear» o sistema para o fazer funcionar. Ao usar um Túnel, todo o tráfego é gerido pelo serviço que estamos a usar, não pelo OBSD. O facto fascinante é que não precisamos de abrir portas Extra para aceitar ligações do mundo exterior, e podemos validar todos os pedidos http usando a API da Cloudflare, para ter a certeza de que todas as ligações que aceitamos vêm de uma fonte de confiança. Os programadores estão integrados em projectos fantásticos, independentes do sistema principal do OBSD. Estas pessoas preocupam-se em criar um sistema estável e seguro e, com isso em mente, sinto-me seguro. Comecei a ler sobre a shell predefinida que usam, que é a Korn Shell, cuja documentação qualquer um encontra no site da IBM, e há outra comunidade chamada SpaceWorks que é uma fonte Fantástica de Informação e uma plataforma muito boa para esclarecer dúvidas. Nesta pesquisa sobre «como usar o OBSD» sem instalar (demasiado software extra), estou a aprender um pouco mais sobre o fluxo do OBSD. Por exemplo, gosto mesmo de saber a diferença entre pastas e ficheiros; como não descobri como configurar as cores dos ficheiros listados, posso usar (alias ls='ls -F') no .profile e, com isso, vejo se os ficheiros listados são ficheiros ou pastas. Seria o mesmo usando 'ls -p'. Enfim, gosto sempre de ter esta sensação de que estou a melhorar tudo o que sei, com algo que me dá uma nova sensação de estabilidade e segurança. Nada é indestrutível e nada é eterno, mas este projecto é feito por muitos utilizadores com muita experiência em C, C++, Rust, Go, Python, Perl e muitas outras linguagens que podem ser úteis em qualquer sistema. Continuo em dúvida sobre o que é melhor (entre VMMs puros ou Qemu). Como o Qemu tem melhor suporte de Gráficos, usar Qemu pode ter algumas vantagens, mesmo que o objectivo principal seja usar um Linux sem X. Vou continuar a testar enquanto aprendo.

I figure out that OpenBSD can be my main operating system

In case I wish to use this OS as a Firewall, I should try to use it, without installing any extra software, to be sure that my "Router" is secure. But, by reading OpenBSD documentation, I see that is possible to use this OS as a Desktop with Firefox, and many other software that I normally use when using Linux. In fact, I can even emulate a Linux box inside OBSD and run the applications that I like to run that are not in OBSD, to access them with easy. The popularity of this OS is not big, while I am not searching for popularity, but for stability. By default, if you try to use Firefox the system will be damn slow and You may ask: "But why?". The answer is on the default configurations that OBSD runs on. If you change it, you will have a "fast OS" without being damn slow. Is less secure? ( probably is, but if you are not serving any public service, is not a big deal to change those configurations ). So, I start trying to use 'vi' without install 'vim'. Is a bit strange, since there a few changes, but if you know how to play with Vim, then 'vi' will be a bit different but not so much. There is no default browser, therefor, I need to install a minimal package, like 'w3m' or 'elinks', which are my favorite browsers for the terminal. With this in mind, I can configure a machine to be a dedicated firewall, while having others that are not, but Desktops. Sadly, at least for me, I need to have a dedicated machine using Linux, since the Cloudflared application to create a tunnel between my personal server and Cloudflare servers, don't run on OBSD or in FBSD. At that point, I will keep the most accessible Linux OS in the world, which is (in my opinion, Debian). I can run it inside a VM or in a dedicated Machine. For this, I really prefer to dedicate a Machine for this, since I can run all the necessary software, without hacking the system to make it work. When using a Tunnel, all traffic is managed by the service we are using, not by OBSD. The fascinating fact is that, we don't need to open Extra ports to accept connections from the outside world, and we can validate all http requests using Cloudflare API, to be sure that all connections we accept, are from a trusted source. The developers are integrated with awesome projects, that are independent from OBSD main OS. These people care to create a stable and secure OS and with that in mind, I feel safe. I start to read about the default shell they use, which is the Korn Shell, which anyone can find some documentation in the IBM site, while there is another community called SpaceWorks that is a Awesome source of Information and a very nice platform to clear our doubts. In this research on "how to use OBSD" without installing (too much extra software), I am learning a bit more about OBSD flow. For example, I really like to know the difference betweeen folder and files, which I didn't find how to setup colors of the listed files, I can use the (alias ls='ls -F') in the .profile and with that, I can see if the listed files are files or folders. It would be the same if using 'ls -p'. Anyway, I always like to have this sensation that I am upgrading everything I know, with something that give me a new sensation of stability and security. Nothing is unbreakable and nothing is eternal, but this project is made by many users that are very experienced with C, C++, Rust, Go, Python, Perl and many others languages that may be useful to use in any OS. I am still in doubt about what is best (between pure VMMsor Qemu). Because Qemu have better suport for Graphics, using Qemu can have some advanges, even if the main objective is to use a Linux without X. I will continue testing while learning.
