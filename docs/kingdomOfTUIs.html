Terminal Handbook · Application Atlas

Kingdom of TUIs

A terminal user interface is a program that owns the screen of your terminal and behaves like an application: a file manager with panels, a monitor with graphs, a Git client with staging, a database browser. No window manager, no mouse required, no browser engine — just cells, keys and colour. This page is a field guide to the applications you can actually install on Linux today, with their GitHub projects, so you can jump straight to the source and the README.

Everything below runs inside a plain terminal on Linux. Most are single binaries or small packages; a few need a helper service (music players that speak MPD, for example). The lists are organised by what you are trying to get done, not by language or framework, because that is how you will look for them. If a project is marked popular, it is one of the ones with the largest GitHub communities — a proxy for documentation, issues answered, and years of bug reports.

File managers 9

Yazipopular

Async file manager in Rust with image, video and archive previews. Extremely fast on huge directories and pleasant to theme.

Rust · Linux, macOS

ranger

The classic three-column, vi-inspired file manager. Python, previews, bookmarks, and a plugin ecosystem that has aged well.

Python · Linux, macOS, BSD

lf

Ranger's spirit written in Go: one binary, configurable keybindings, shell integration, and no Python runtime to carry around.

Go · Linux, macOS, BSD

nnn

Very small C file manager with a plugin system, session handling and batch operations. The one to install on a rescue system.

C · Linux, macOS, BSD

Vifm

Dual-pane file manager with genuine Vim keybindings, registers and a command line. Feels like editing a filesystem.

C · Linux, macOS, BSD

broot

Not a manager but a navigator: fuzzy search across the tree, preview panels, and a language for composing filesystem queries.

Rust · Linux, macOS

Superfile

A modern-looking two-pane manager with themes and a friendly default keymap. Aimed at people who find ranger too spartan.

Go · Linux, macOS

joshuto

Ranger-like columns and previews in Rust, with a configuration file you can actually read in one sitting.

Rust · Linux, macOS

xplr

A hackable file explorer built around piping and Lua configuration. More of a toolkit than a fixed application.

Rust · Linux, macOS

System monitoring 7

btop++popular

CPU, memory, disks, network and processes with real graphs and themes. The modern replacement for top in most setups.

C++ · Linux, macOS, BSD

bottom

Cross-platform monitor with configurable widgets, temperature and battery support, and a clean TOML configuration.

Rust · Linux, macOS, Windows

htop

The dependable classic: process tree, per-core load, kill and renice. Still the default answer to "what is eating my CPU".

C · Linux, macOS, BSD

Glances

Everything-in-one monitor with containers, sensors and a web mode. Useful when you want one tool that covers the whole host.

Python · Linux, macOS, Windows

Zenith

Historical graphs for CPU, memory, disks and GPU. Good for spotting trends rather than staring at instant numbers.

Rust · Linux, macOS

nvtop

GPU processes and utilisation for NVIDIA, AMD and Intel. Indispensable when a training job eats the wrong card.

C · Linux

s-tui

CPU temperature, frequency and stress testing in one screen. A quick way to find out whether the fan curve is lying.

Python · Linux, macOS

Git and GitHub 4

lazygitpopular

Stage hunks, rebase, stash, resolve conflicts and browse branches without typing a single command. The gateway drug of Git TUIs.

Go · Linux, macOS, Windows

GitUI

A fast Rust Git client with staging, diff review and log browsing. Written for large repositories and slow laptops.

Rust · Linux, macOS, Windows

tig

An ncurses interface to Git as a repository browser: commits, trees, blame and diffs, with keys that resemble Git's own commands.

C · Linux, macOS, BSD

gh-dash

A dashboard for your GitHub pull requests and issues, built on the official CLI. Triage without opening a browser tab.

Go · Linux, macOS, Windows

Containers and Kubernetes 5

k9spopular

A Kubernetes dashboard that replaces a pile of kubectl commands: pods, logs, shells, port-forwards and events, all with keyboard navigation.

Go · Linux, macOS, Windows

lazydocker

Containers, images, volumes and logs in one screen, with restart and shell actions on a keystroke. Docker without the typing.

Go · Linux, macOS, Windows

dive

Inspect Docker image layers and see exactly which files each step added, changed or wasted. A diet tool for fat images.

Go · Linux, macOS, Windows

ctop

Top for containers: CPU, memory and network per container, with the same instinctive keys as the classic process monitor.

Go · Linux, macOS

podman-tui

The Podman project's own terminal interface: pods, containers, images, networks and volumes, for rootless workflows.

Go · Linux

Databases and HTTP 4

LazySQL

Browse MySQL, PostgreSQL, SQLite and SQL Server databases, run queries and edit rows in place. A GUI client without the GUI.

Go · Linux, macOS, Windows

Harlequin

A SQL IDE for the terminal with a schema browser, autocomplete and result export. Particularly good with DuckDB and SQLite.

Python · Linux, macOS, Windows

dblab

An interactive client for PostgreSQL, MySQL and SQLite with table navigation and query history. Small and focused.

Go · Linux, macOS, Windows

Posting

An HTTP client that feels like a good editor: collections, environments, request history and syntax-highlighted bodies. A terminal answer to heavyweight API tools.

Python · Linux, macOS, Windows

Network analysis 5

termshark

A terminal UI for tshark: capture, filter, inspect packets and follow streams without leaving the shell. The closest thing to Wireshark in a TUI.

Go · Linux, macOS, Windows

bandwhich

Shows which process, connection and remote host is using your bandwidth, live. The fastest answer to "why is the network slow".

Rust · Linux, macOS

Trippy

A modern traceroute with live latency, jitter and loss per hop, plus maps and reports. Replaces the ancient traceroute ritual.

Rust · Linux, macOS, Windows

nethogs

Bandwidth grouped by process rather than by socket. Old, tiny and still the quickest way to catch a rogue daemon.

C++ · Linux

wavemon

Wi-Fi signal strength, noise, bitrate and channel usage over time. For when the connection drops and the graph explains why.

C · Linux

Music, video and reading 9

cmus

A small, fast music player with a library, playlists, gapless playback and a keymap that becomes muscle memory in a week.

C · Linux, macOS, BSD

ncmpcpp

The most complete MPD client: library, playlists, visualiser, lyrics and tag editing. Needs an MPD server, rewards the setup.

C++ · Linux, macOS, BSD

termusic

A Rust music player with built-in YouTube download support, album art in some terminals, and a modern keymap.

Rust · Linux, macOS, Windows

spotify_player

Spotify in the terminal: search, playlists, devices and lyrics. Requires a Spotify account and its own API setup.

Rust · Linux, macOS, Windows

castero

A podcast client with subscriptions, playback queue and variable speed. Simple, and it keeps your feeds local.

Python · Linux, macOS

Newsboat

The RSS and Atom reader that refuses to die: OPML import, killfiles, macros and a search that reads like a query language.

C++ · Linux, macOS, BSD

ytfzf

Search YouTube from the terminal and play the result in mpv. A shell script that turns a browser habit into a command.

Shell · Linux, macOS

chafa

Renders images as text or as real terminal graphics where supported. The reliable way to look at a PNG without leaving the shell.

C · Linux, macOS

viu

A tiny Rust image viewer for terminals with true colour and kitty/iTerm graphics support. One command, instant preview.

Rust · Linux, macOS, Windows

Irssi

The IRC client that entire generations configured once and never again. Scriptable in Perl, stable, and still maintained.

C · Linux, macOS, BSD

Multi-protocol chat with IRC at its core and plugins for Matrix and more. Scriptable in several languages, with relay support.

C · Linux, macOS, BSD

C · Linux, macOS, BSD

A terminal client for Mattermost and Slack-style teams, with threads, notifications and file uploads. Niche but well built.

Haskell · Linux, macOS

Go · Linux, macOS, Windows

A modal editor with multiple selections and treesitter built in. Sensible defaults, no plugin ceremony, works out of the box.

Rust · Linux, macOS, Windows

Modal editing built around selections and a client-server model. The design that inspired several newer editors.

A modern terminal editor with familiar shortcuts, mouse support and a plugin manager. The answer for people who do not want Vim.

Go · Linux, macOS, Windows

Vim's successor: Lua configuration, built-in LSP, treesitter and an enormous plugin ecosystem. A terminal editor that became a platform.

C, Lua · Linux, macOS, Windows

Go · Linux, macOS, Windows

Go · Linux, macOS, Windows

A Rust presentation tool with themes, images, code execution and speaker notes. More features than you expect from a terminal.

Rust · Linux, macOS, Windows

Rust · Linux, macOS, Windows

Shell · Linux

Go · Arch Linux

Go · Linux

Bluetooth device management, pairing and audio profiles without a desktop applet. Useful on minimal window managers.

Go · Linux

Mixer for PulseAudio and PipeWire: volumes, devices, profiles and muting, with keys and mouse. A volume applet for the terminal.

Where to find thousands more

No page can list them all. The community maintains large, curated indexes: rothgar/awesome-tuis is the best starting point, organised by category and kept current. The awesome-ratatui list is a good second door if you want to see what the Rust ecosystem alone has produced. Search GitHub for the topics tui, terminal-ui and curses, sort by stars, and read the last release date before you commit to anything.

Two related pieces on this blog: Rust TUIs that I love, a personal tour of applications built with the Rust ecosystem, and The correct name should be SUIs, an argument about how these interfaces should be classified. If you want a terminal browser in the same spirit, W3M Browser is the classic example.
