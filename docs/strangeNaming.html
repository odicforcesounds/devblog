Native means "of the house"

A native application is one written with the tools of the platform itself. Android speaks Java and Kotlin, iOS speaks Swift and Objective-C, and each of those languages has a direct line to the screen, the microphone and the battery. That is what makes an application feel like it belongs to the device.

React Native is something else. The logic is JavaScript, the interface is described once, and the result is translated into the native widgets of each system. So the code is not native, the result is. The name describes the output, not the tool.

Where the confusion comes from

React is a way of building interfaces for the web. Native is an adjective about a platform. Put the two words together and the reader expects a language, and gets a bridge. That is a name that explains itself to the people who already know the answer, and confuses everyone else.

Which is not a crime. Naming is hard, and a name is chosen by people in a hurry, usually after a shorter name was already taken. The rest of us live with a vocabulary that describes history instead of function.

My rule for names

A program should be named for what it does, not for what it is made of, and never for what it used to be. Java is a coffee, Android is a robot, React is a verb. None of them describes the work, and all of them are memorable, which tells us something honest about how much of technology is marketing with a compiler attached.
