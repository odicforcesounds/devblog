01.

Introduction & Modal Philosophy

Traditional editors assume every key press inserts text. Vim assumes you spend most of your time reading, navigating, and refactoring code, reserving typing for specific modes.

Normal Mode Esc / Ctrl+[

The command hub. Keys act as actions, navigation commands, and operators rather than text inputs.

Insert Mode i / a / o

Standard typing mode. Keypresses insert literal characters into the active buffer.

Visual Mode v / V / Ctrl+v

Highlight text regions character-wise (v), line-wise (V), or block-wise (Ctrl+v).

Command-Line : / ? / !

Execute Ex commands for saving, quitting, buffer operations, search, and system execution.

Select Mode gh

Behaves like traditional IDE text highlighting where typing immediately overwrites selection.

Terminal Mode :terminal

Interacts with an embedded terminal shell directly inside a Vim window split.

02.

Basic Navigation & Fundamental Editing

Master home-row navigation and fundamental editing mechanics before learning complex sequences.

Category Keys Action Description
Core Directional h j k l Left, Down, Up, Right (keep hands on home-row)
Word Motions w / W | b / B Next word / WORD start | Previous word / WORD start
Word Endings e / E | ge / gE Forward to end of word / WORD | Backward to end of word / WORD
Line Bounds 0 | ^ | $ Column 0 (absolute start) | First non-whitespace char | End of line
Inline Character Find f{char} / t{char} Find character forward / Till character forward (place cursor before)
Repeat Find ; / , Repeat last f/t search forward / Repeat backward
Vertical Paging Ctrl+u / Ctrl+d Scroll half-page Up / Scroll half-page Down
File Navigation gg / G | {num}G First line of buffer / Last line of buffer | Jump directly to line {num}
The Dot Operator (.)
The single most powerful core command in Vim. . repeats the last editing change (e.g., cw + type word + Esc, then hit . on another word to instantly replace it).
03.

Text Objects & Advanced Motions

Text objects allow operating on structural constructs (words, quotes, brackets, tags) regardless of where the cursor is inside the object.

Inner (i) vs Around (a)
  • i targets only the content inside the boundaries.
  • a targets the content PLUS surrounding delimiters & whitespace.
Common Target Objects
  • w / s / p - Words, Sentences, Paragraphs
  • ", ', ` - Single, Double, or Backtick Quotes
  • (, [, {, < - Parentheses, Brackets, Braces, Angle brackets
  • t - HTML / XML Tags
Expression Command Target Text Resulting Action
ciw const variable = true; Deletes inner word and drops into Insert mode.
di" console.log("Hello World"); Wipes text inside quotes, keeping empty quotes "".
da( func(arg1, arg2); Deletes parentheses AND everything contained inside.
cit <h1>Page Title</h1> Changes contents between opening and closing HTML tags.
04.

Registers, Marks & Macros

Store text snippets, bookmark arbitrary code lines, and record repetitive keystroke sequences for massive automation.

Key Registers "{reg}
  • "" Unnamed register (last delete/yank)
  • "0 Last yank register (unaffected by deletes)
  • "+ System Clipboard (OS copy/paste)
  • "_ Blackhole register (discards text)
  • "= Expression evaluation calculator
Jump Marks m{mark}
  • ma Set local mark a for current buffer
  • mA Set global mark A across buffers
  • 'a Jump to line of mark a
  • `a Jump to exact column & line of mark a
  • '' Jump back to location before last jump
Macros q{reg}
  • qa Start recording keystrokes into register a
  • q Stop recording macro
  • @a Execute macro a once
  • @@ Repeat last executed macro
  • 10@a Run macro a 10 times consecutively
05.

Splits, Buffers, Windows & Tabs

Understand the core distinction: A Buffer is a file loaded into memory. A Window is a viewport into a buffer. A Tab is a collection of window viewports.

Buffer Operations
  • :ls or :buffers — List active memory buffers
  • :bnext (:bn) / :bprev (:bp) — Cycle buffers
  • :b {num_or_name} — Switch to buffer ID or partial match
  • :bdelete (:bd) — Unload buffer without quitting
Window Splits
  • :sp / :vsp — Horizontal / Vertical window split
  • Ctrl+w h/j/k/l — Move focus between split directions
  • Ctrl+w = — Equalize dimensions of all open splits
  • Ctrl+w o — Close all splits except current active window
06.

Power User Built-in Features (Zero Plugins Required)

Vim comes out of the box with built-in tools that eliminate the absolute necessity for third-party extensions.

Built-In Power Workflows
" 1. Netrw File Explorer (Native file tree)
:Ex             " Open Netrw file explorer in current window
:Vex            " Open Netrw in vertical split
" Inside Netrw: 'd' creates dir, '%' creates file, 'R' renames

" 2. Global Command (:g) - Run Ex actions on pattern matches
:g/^$/d         " Delete all empty lines in entire file
:g/TODO/t$       " Copy all lines containing 'TODO' to end of file
:v/DEBUG/d      " Delete all lines that DO NOT match 'DEBUG'

" 3. Quickfix List - Project-wide Search & Replace
:vimgrep /getUser/ src/**/*.ts
:copen          " Open quickfix results window
:cfdo %s/getUser/fetchUser/g | update " Batch substitute across all search files

" 4. Native Autocompletion (Insert Mode)
Ctrl+n / Ctrl+p  " Keyword match in current / open buffers
Ctrl+x Ctrl+f  " File path autocompletion
Ctrl+x Ctrl+l  " Whole line autocompletion

The Ultimate Vanilla .vimrc Masterclass

A production-ready, sensible configuration file written in standard Vimscript.

~/.vimrc
" ============================================================================ " PRODUCTION-READY VANILLA .VIMRC " ============================================================================ set nocompatible " Disable Vi compatibility mode filetype plugin indent on " Enable filetype detection and auto-indent syntax on " Enable syntax highlighting " --- UI Settings --- set number " Absolute line number on cursor set relativenumber " Relative line numbers for easy jump motions set cursorline " Highlight current line set scrolloff=8 " Keep 8 padding lines visible above/below cursor set signcolumn=yes " Always display sign column to prevent layout shifts set termguicolors " Enable 24-bit True Color support set wildmenu " Enhanced visual command-line completion set wildmode=longest:full,full " --- Indentation & Tabs --- set tabstop=4 " Visual spaces per TAB set softtabstop=4 " Spaces inserted while editing set shiftwidth=4 " Spaces used for auto-indenting set expandtab " Convert tabs to spaces set autoindent smartindent " Smart code indentation logic " --- Search & Splitting --- set ignorecase smartcase " Case-insensitive unless query contains Capital set incsearch hlsearch " Incremental search & persistent highlights set splitbelow splitright " Natural split orientation (bottom & right) " --- History & Undo --- set hidden " Allow switching buffers without saving set undofile " Persistent undo trees saved across reboots set undodir=~/.vim/undodir " --- Custom Keymappings --- let mapleader = " " " Set Spacebar as Leader key " Fast saving & quitting nnoremap <Leader>w :w<CR> nnoremap <Leader>q :q<CR> " Clear search highlight using Space + h nnoremap <Leader>h :nohlsearch<CR> " Keep selection highlighted when shifting indents vnoremap < <gv vnoremap > >gv
08.

The Modern Vim / Neovim Plugin Ecosystem

When pure vanilla functionality needs extending, these modern plugins transform Vim into a lightning-fast modern IDE.

lazy.nvim / vim-plug Plugin Managers

High-performance plugin managers featuring lazy loading, concurrent installation, and lockfile versioning.

Telescope.nvim / fzf.vim Fuzzy Finder

Asynchronous fuzzy search windows over files, git commits, LSP symbols, and live project grep results.

nvim-treesitter Syntax Parsing

Uses incremental AST parsers for context-aware syntax highlighting, scope selection, and code folding.

Mason & nvim-lspconfig LSP Integration

Seamlessly installs and hooks language servers directly into built-in autocompletion and linting diagnostics.

Oil.nvim / nvim-tree File Management

Edit directory files directly like a Vim buffer (Oil) or display a modern file tree explorer sidebar.

Mini.surround / vim-surround Text Surround

Adds surround verbs: cs"' (change double quotes to single), ds( (delete parens), ysiw) (add parens to word).
