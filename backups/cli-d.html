16Keeping it clean for a year

An install is a decision you keep paying for: every tool has a version, a cache and a folder. The maintenance is small if it is regular — five minutes a month, four commands, and the machine never accumulates the kind of Python installation nobody dares touch. 

pipx upgrade-all                 # every app, in its own venv
uv tool upgrade --all            # if you use uv
pip cache purge                  # wheels you will never need again
uv cache clean
du -sh ~/.venvs/* | sort -h      # the environments you forgot

Audit before you trust

A tool's dependencies are code you run with your permissions. pipx run pip-audit checks an environment against the public vulnerability database, and pipx list --include-injected reminds you what you added by hand. Neither is a guarantee; both catch the obvious.

The rule of the second install

Install a tool the first time because you need it. Install it the second time — after removing it, with a different method — because you now know how you use it. Everything installed "just in case" becomes the folder you skip when backing up.

17The ten messages that stop an install

These are not ten problems. They are three: the wrong interpreter, a missing system library, or a directory the shell cannot see. The table maps the message to the cause, because the message is almost never the cause.

Message What it means Fix
error: externally-managed-environment You are installing into the distribution's Python, which PEP 668 now blocks on purpose. Create a venv, or use pipx install. Do not use --break-system-packages.
command not found: yt-dlp after a successful install The launcher is in ~/.local/bin, which is not on PATH in this shell. Run pipx ensurepath, open a new terminal, or export PATH="$HOME/.local/bin:$PATH" and hash -r.
ModuleNotFoundError: No module named 'X' The package is installed for a different interpreter than the one running the script. Compare which python with the install line, then reinstall using python -m pip from the same environment.
error: Microsoft Visual C++ 14.0 or greater is required No prebuilt wheel exists for this package and this Python on Windows. Try a newer Python (more wheels), use --only-binary :all: to see what is available, or install the Build Tools.
fatal error: Python.h: No such file or directory The package compiles a C extension and the Python development headers are missing. sudo apt install python3-dev (Debian), python3-devel (Fedora), then retry.
ERROR: No matching distribution found for X Usually a Python version below the project's floor, a misspelled name, or no network. Check the project's Requires-Python on PyPI, confirm the exact package name, then try a newer interpreter.
SSL: CERTIFICATE_VERIFY_FAILED The Python from python.org on macOS ships without a certificate bundle, or a proxy intercepts TLS. Run Install Certificates.command in the Python folder, or pip install --upgrade certifi. On a corporate proxy, set REQUESTS_CA_BUNDLE.
Killed while building a package The compiler ran out of memory — common on a 1 GB VPS with a large source build. Add swap, or avoid compiling: prefer --only-binary :all:, or install the app where wheels exist for your platform.
Permission denied: /usr/lib/python3/dist-packages A previous sudo pip install left root-owned files, and now pip cannot clean up after itself. Stop using sudo for pip. Uninstall what you added with sudo, fix ownership if needed (sudo chown -R $USER on the user-writable parts), and move to venv or pipx.
Could not build wheels for X, which is required to install pyproject.toml-based projects The package needs a system library or a compiler the machine does not have — pango, ffmpeg, tesseract, libpq. Install the system package named in the error, then retry. The app chapters in this manual list which one each tool needs.
Read the last line, not the first

pip prints a page of resolver output and the useful sentence is at the very end, after ERROR:. Copy the last ten lines, not the whole log, when you search for the message — and add the Python version and the operating system, because half the answers online are for a different pair.
